トースト通知

一時的なフィードバックメッセージを画面の隅に表示し、自動的に消えるUI。操作の結果（成功・エラー等）をユーザーに伝えます。

⚠

i

設計の意図

aria-live="polite" で通知をアクセシブルに
aria-live="polite" を設定したコンテナに要素を追加すると、スクリーンリーダーが現在の読み上げを中断せずに通知内容を読み上げます。エラーなど緊急性の高いものには "assertive" を使います。

自動消去と手動閉じの併用
成功メッセージは3〜5秒で自動消去、エラーは手動で閉じるまで残すのが一般的です。自動消去だけだと「読む前に消えた」問題が起き、手動だけだと「閉じるのが面倒」になります。

スタッキング（積み重ね）
複数のトーストが同時に出る場合、上から下に積み重ねます。flex-direction: column と gap で自然に配置されます。

コード解説

<!-- aria-live="polite" → 動的に追加されたコンテンツを
     スクリーンリーダーが自動的に読み上げる -->
<div class="toast-container" aria-live="polite" aria-atomic="true">

  <!-- トースト1つ分 -->
  <div class="toast toast--success" role="status">
    <div class="toast__icon">✓</div>
    <div class="toast__content">
      <div class="toast__title">保存完了</div>
      <div class="toast__message">データが正常に保存されました。</div>
    </div>
    <button class="toast__close" aria-label="閉じる">×</button>
  </div>
</div>
/* --- トーストコンテナ：画面右上に固定 --- */
.toast-container {
  position: fixed;
  top: 16px;
  right: 16px;
  z-index: var(--z-toast);
  display: flex;
  flex-direction: column; /* 上から下に積み重ねる */
  gap: 8px;
  pointer-events: none;   /* コンテナ自体はクリック透過 */
}

/* --- スライドインアニメーション --- */
@keyframes toast-slide-in {
  from {
    transform: translateX(120%); /* 右端の外から */
    opacity: 0;
  }
  to {
    transform: translateX(0);
    opacity: 1;
  }
}

/* --- スライドアウト（消える時） --- */
@keyframes toast-slide-out {
  from { transform: translateX(0); opacity: 1; }
  to   { transform: translateX(120%); opacity: 0; }
}

/* --- 種類ごとの左ボーダー色 --- */
.toast--success { border-left: 3px solid var(--color-state-success); }
.toast--error   { border-left: 3px solid var(--color-state-error); }
.toast--warning { border-left: 3px solid var(--color-state-warning); }
.toast--info    { border-left: 3px solid var(--color-state-info); }
// アイコンマッピング
const ICONS = {
  success: '✓', error: '!', warning: '⚠', info: 'i'
};

function showToast(type, title, message, duration = 4000) {
  const container = document.getElementById('toast-container');

  // トースト要素を生成
  const toast = document.createElement('div');
  toast.className = `toast toast--${type}`;
  toast.setAttribute('role', 'status');

  toast.innerHTML = `
    <div class="toast__icon">${ICONS[type]}</div>
    <div class="toast__content">
      <div class="toast__title">${title}</div>
      <div class="toast__message">${message}</div>
    </div>
    <button class="toast__close" aria-label="閉じる">×</button>
  `;

  // 閉じるボタンのイベント
  toast.querySelector('.toast__close')
    .addEventListener('click', () => removeToast(toast));

  // コンテナに追加
  container.appendChild(toast);

  // 自動消去：指定時間後にスライドアウト
  if (duration > 0) {
    setTimeout(() => removeToast(toast), duration);
  }
}

function removeToast(toast) {
  toast.classList.add('is-leaving');
  // アニメーション終了後にDOMから削除
  toast.addEventListener('animationend', () => toast.remove());
}
