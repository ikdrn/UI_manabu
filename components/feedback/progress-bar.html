設計の意図

確定型 vs 不定形型の使い分け
進捗が数値でわかる場合（ファイルアップロードなど）は確定型、完了時間が不明な場合（サーバー処理待ちなど）は不定形型を使います。不定形型はアニメーションで「処理中」を伝えます。

conic-gradient による円形プログレス
SVGを使わずCSSだけで円形プログレスを実現できます。CSS変数 --progress の値を変えるだけで進捗を更新でき、JavaScriptとの連携が簡単です。

role="progressbar" + aria-valuenow
スクリーンリーダーに「このバーは進捗を示している」「現在の値は65%」と伝えます。不定形の場合は aria-valuenow を省略し、「進捗中（値不明）」と伝えます。

コード解説

<!-- === 線形プログレスバー === -->
<!-- role="progressbar" → プログレスバーであることを示す -->
<!-- aria-valuenow → 現在の値 -->
<!-- aria-valuemin/max → 最小値と最大値 -->
<div class="progress" role="progressbar"
     aria-valuenow="65" aria-valuemin="0" aria-valuemax="100"
     aria-label="アップロード進捗">
  <div class="progress__bar" style="width: 65%"></div>
</div>

<!-- === 不定形（完了時間不明） === -->
<!-- aria-valuenow を省略 → 「値が不明」を意味する -->
<div class="progress progress--indeterminate"
     role="progressbar" aria-label="読み込み中">
  <div class="progress__bar"></div>
</div>

<!-- === 円形プログレス === -->
<!-- CSS変数 --progress でconic-gradientの角度を制御 -->
<div class="progress-circular"
     style="--progress: 75" data-value="75"
     role="progressbar" aria-valuenow="75"></div>

<!-- === ステップインジケーター === -->
<div class="steps" role="group" aria-label="注文ステップ">
  <div class="step step--completed">
    <div class="step__circle">✓</div>
    <span class="step__label">カート</span>
  </div>
  <div class="step step--current">
    <div class="step__circle">2</div>
    <span class="step__label">お支払い</span>
  </div>
</div>
/* --- 線形プログレスバー --- */
.progress {
  width: 100%;
  height: 8px;
  background: var(--color-neutral-200); /* 未完了部分の色 */
  border-radius: 9999px;
  overflow: hidden; /* バーが角丸からはみ出さないように */
}

.progress__bar {
  height: 100%;
  background: var(--color-brand-500);
  border-radius: 9999px;
  /* width を transition で滑らかに変化 */
  transition: width 250ms ease-out;
}

/* --- 不定形：左右にスライドするアニメーション --- */
.progress--indeterminate .progress__bar {
  width: 40%;
  animation: indeterminate-slide 1.5s ease-in-out infinite;
}

@keyframes indeterminate-slide {
  0%   { transform: translateX(-100%); }
  100% { transform: translateX(350%); }
}

/* --- 円形プログレス（conic-gradient） --- */
.progress-circular {
  width: 80px;
  height: 80px;
  border-radius: 50%;
  /* conic-gradient → 扇形のグラデーション
     calc(var(--progress) * 1%) で進捗分だけ塗る */
  background: conic-gradient(
    var(--color-brand-500) calc(var(--progress) * 1%),
    var(--color-neutral-200) 0
  );
}

/* 中央をくり抜いてドーナツ型にする */
.progress-circular::after {
  content: attr(data-value) '%'; /* data属性から値を取得 */
  width: 62px; height: 62px;
  background: white;
  border-radius: 50%;
}

/* --- ステップ間の接続線 --- */
.step + .step::before {
  content: '';
  position: absolute;
  top: 16px; /* 丸の中心に合わせる */
  right: 50%;
  width: 100%;
  height: 2px;
  background: var(--color-neutral-200);
}

/* 完了ステップの次の線を色変え */
.step--completed + .step::before {
  background: var(--color-state-success);
}
// プログレスバーの値を更新する関数
function updateProgress(progressEl, value) {
  const bar = progressEl.querySelector('.progress__bar');
  bar.style.width = value + '%';
  progressEl.setAttribute('aria-valuenow', value);
}

// 円形プログレスの値を更新する関数
function updateCircularProgress(el, value) {
  el.style.setProperty('--progress', value);
  el.setAttribute('data-value', value);
  el.setAttribute('aria-valuenow', value);
}

// デモ用スライダー連動
const slider = document.getElementById('demo-slider');
slider.addEventListener('input', (e) => {
  const value = e.target.value;
  document.getElementById('demo-bar').style.width = value + '%';
  document.getElementById('demo-label').textContent = value + '%';
});
