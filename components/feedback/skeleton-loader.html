スケルトンローダー

コンテンツの読み込み中に、最終的なレイアウトの骨格を先に表示するUI。ユーザーに「何がどこに表示されるか」を予告し、体感的な待ち時間を短縮します。

リストスケルトン

設計の意図

なぜスピナーではなくスケルトンを使うのか？
スピナーは「何かが読み込まれている」としか伝えませんが、スケルトンは「何がどのような形で表示されるか」を予告します。これにより体感的な待ち時間が短く感じられ、コンテンツが表示された時のレイアウトシフトも防げます。

シマーアニメーションの仕組み
linear-gradient で明るい帯を作り、background-position をアニメーションで左から右に動かすことで「光が流れる」効果を実現します。background-size を要素幅より大きくすることで帯が端から端まで流れます。

aria-busy="true" で読み込み状態を伝える
スケルトン表示中のコンテナに aria-busy="true" を設定すると、スクリーンリーダーが「この領域はまだ読み込み中」であることを理解します。読み込み完了後に false に変更します。

コード解説

<!-- aria-busy="true" → コンテンツ読み込み中であることを示す -->
<div id="card-container" aria-busy="true">

  <!-- スケルトン：最終レイアウトと同じ構造で配置 -->
  <div class="skeleton-card">
    <div class="skeleton-card__header">
      <!-- 丸い形 → アバターの骨格 -->
      <div class="skeleton skeleton--avatar"></div>
      <div>
        <!-- 長方形 → テキストの骨格 -->
        <div class="skeleton skeleton--text" style="width:40%"></div>
        <div class="skeleton skeleton--text" style="width:25%"></div>
      </div>
    </div>
    <!-- 大きい長方形 → 画像の骨格 -->
    <div class="skeleton skeleton--image"></div>
    <div class="skeleton skeleton--text"></div>
    <div class="skeleton skeleton--text" style="width:70%"></div>
    <div class="skeleton skeleton--button"></div>
  </div>

  <!-- 実コンテンツ：読み込み完了後に表示 -->
  <div class="loaded-card" style="display:none">
    実際のコンテンツ...
  </div>
</div>
/* --- シマーアニメーション --- */
@keyframes shimmer {
  0%   { background-position: -400px 0; }
  100% { background-position: 400px 0; }
}

.skeleton {
  /* ベース色：薄いグレー */
  background: var(--color-neutral-200);

  /* linear-gradient → 左から右に流れる明るい帯 */
  background-image: linear-gradient(
    90deg,
    var(--color-neutral-200) 0%,    /* 左端：通常色 */
    var(--color-neutral-100) 40%,   /* 中央：少し明るい */
    var(--color-neutral-200) 80%    /* 右端：通常色に戻る */
  );

  /* background-size → 要素幅より大きくすることで
     帯が端から端まで移動できるスペースを確保 */
  background-size: 400px 100%;

  /* シマーアニメーション */
  animation: shimmer 1.5s ease-in-out infinite;
  border-radius: 4px;
}

/* --- 形状バリエーション --- */
.skeleton--text   { height: 14px; }          /* テキスト行 */
.skeleton--avatar { width: 48px; height: 48px;
                    border-radius: 50%; }    /* 丸いアバター */
.skeleton--image  { height: 180px;
                    border-radius: 8px; }    /* 画像プレースホルダー */

/* --- フェードイン --- */
@keyframes fade-in {
  from { opacity: 0; }
  to   { opacity: 1; }
}

.loaded-card {
  animation: fade-in 250ms ease-out;
}
// データ読み込み完了後にスケルトン → 実コンテンツに切り替え
async function loadContent() {
  const container = document.getElementById('card-container');
  const skeleton = document.getElementById('skeleton-card');
  const loaded = document.getElementById('loaded-card');

  // データ取得（API呼び出しなど）
  const data = await fetchData();

  // スケルトンを隠して実コンテンツを表示
  skeleton.style.display = 'none';
  loaded.style.display = 'block';

  // aria-busy を false に更新
  // → スクリーンリーダーに「読み込み完了」を伝える
  container.setAttribute('aria-busy', 'false');
}

// トグルボタンでデモ
const toggleBtn = document.getElementById('toggle-card');
let isLoaded = false;

toggleBtn.addEventListener('click', () => {
  isLoaded = !isLoaded;
  const skeleton = document.getElementById('skeleton-card');
  const loaded = document.getElementById('loaded-card');
  const container = document.getElementById('card-container');

  if (isLoaded) {
    skeleton.style.display = 'none';
    loaded.style.display = 'block';
    container.setAttribute('aria-busy', 'false');
    toggleBtn.textContent = 'スケルトンに戻す';
  } else {
    skeleton.style.display = 'block';
    loaded.style.display = 'none';
    container.setAttribute('aria-busy', 'true');
    toggleBtn.textContent = '読み込み完了をシミュレート';
  }
});

実運用でのエッジケース

prefers-reduced-motion への対応

アニメーションを減らしたいユーザーのために、@media (prefers-reduced-motion: reduce) でシマーアニメーションを無効化しましょう。スケルトン自体は残し、アニメーションだけ止めるのがベストです。

スケルトンと実コンテンツのサイズ差

スケルトンの形状が実コンテンツと大きく異なると、切り替わった時にレイアウトがガタつきます（CLS：Cumulative Layout Shift）。スケルトンは実コンテンツのレイアウトをできるだけ正確に模倣することが重要です。

長時間の読み込み

5秒以上スケルトンが表示される場合、ユーザーは「壊れている」と感じることがあります。一定時間後に「読み込みに時間がかかっています」といったメッセージを表示するか、リトライボタンを出すことを検討してください。
