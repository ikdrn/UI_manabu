設計の意図

position: absolute + transform でバッジを配置
親要素を position: relative にし、バッジを absolute で右上に配置します。transform で微調整することで、親要素の外にはみ出す「浮いた」表現になります。

パルスアニメーションで注意を引く
重要な通知には ::after 疑似要素でパルス（波紋）アニメーションを追加します。常にアニメーションするとうるさくなるので、本当に重要な通知にのみ使います。

aria-hidden="true" で装飾を隠す
バッジのドットや数字は視覚的な補助です。スクリーンリーダーには親要素の aria-label（例：「通知 3件」）で情報を伝えるので、バッジ自体は aria-hidden にします。

min-width でカウンターの形を保つ
カウンターバッジに min-width を設定することで、1桁でも2桁でも最低限の幅を保ち、きれいな丸い形を維持します。

コード解説

<!-- === ドットバッジ === -->
<!-- ラッパーを position: relative に -->
<div class="badge-dot-wrapper">
  <!-- aria-label でバッジの情報を含める -->
  <button aria-label="通知（未読あり）">🔔</button>
  <!-- バッジ自体は装飾なので aria-hidden -->
  <span class="badge-dot" aria-hidden="true"></span>
</div>

<!-- === パルス付きドット === -->
<span class="badge-dot badge-dot--pulse" aria-hidden="true"></span>

<!-- === カウンターバッジ === -->
<div class="badge-count-wrapper">
  <button aria-label="カート 12件">🛒</button>
  <span class="badge-count" aria-hidden="true">12</span>
</div>

<!-- === ステータスラベル === -->
<span class="badge-label badge-label--success">
  <span class="badge-label__dot"></span>
  アクティブ
</span>
/* --- ドットバッジ --- */
.badge-dot-wrapper {
  position: relative; /* バッジの位置基準 */
  display: inline-flex;
}

.badge-dot {
  position: absolute;
  top: -2px;
  right: -2px;
  width: 10px;
  height: 10px;
  background: var(--color-state-error);
  /* border → 背景色と同じ色のボーダーで「くり抜き」効果 */
  border: 2px solid var(--color-surface-raised);
  border-radius: 9999px;
}

/* --- パルスアニメーション --- */
.badge-dot--pulse::after {
  content: '';
  position: absolute;
  inset: -2px; /* top/right/bottom/left 全て -2px */
  background: var(--color-state-error);
  border-radius: 9999px;
  animation: badge-pulse 1.5s ease-out infinite;
}

@keyframes badge-pulse {
  0%   { transform: scale(1); opacity: 0.6; }
  100% { transform: scale(2.5); opacity: 0; }
}

/* --- カウンターバッジ --- */
.badge-count {
  position: absolute;
  top: -8px;
  right: -8px;
  /* min-width → 1桁でも最低幅を確保して丸い形を保つ */
  min-width: 20px;
  height: 20px;
  padding: 0 6px;
  font-size: 11px;
  font-weight: 700;
  text-align: center;
  line-height: 20px;
  color: white;
  background: var(--color-state-error);
  border: 2px solid var(--color-surface-raised);
  border-radius: 9999px;
}

/* --- ステータスラベル --- */
.badge-label {
  display: inline-flex;
  align-items: center;
  gap: 4px;
  padding: 2px 10px;
  font-size: 12px;
  font-weight: 600;
  border-radius: 9999px; /* ピル型 */
}

.badge-label--success {
  color: var(--color-state-success);
  background: var(--color-state-success-bg);
}

100以上は「99+」と表示してバッジの幅を制限するのが一般的です。

バッジなし（数が0の場合）

通知が0件の時はバッジ自体を非表示にします。
