基本データテーブル

表形式のデータを整理して表示するための基本テーブル。ゼブラストライプとホバーハイライトで行の追跡を助け、適切なセマンティックHTMLでアクセシビリティを確保します。テーブルは「実際の表データ」を表示する時にのみ使い、ページレイアウト目的には使ってはいけません。

設計の意図

テーブルを使うべき場面とは？
テーブルは「2次元の表データ」を表示する時にのみ使います。たとえば社員一覧、料金プラン比較、時刻表など、行と列で交差するデータが意味を持つ場合です。ページの段組みやレイアウトには絶対にテーブルを使わず、CSSのFlexboxやGridを使います。

数字は右揃え、テキストは左揃え
数値を右揃えにすると桁が揃い、数字の大小を瞬時に比較できます。たとえば「2015」と「2023」が右揃えなら、一の位から十の位まで縦に揃って比較しやすくなります。一方、テキストは左揃えが自然で読みやすい方向です。

ゼブラストライプ（交互背景色）の効果
列が多い表では、ある行のデータを横に追う時に隣の行に目が移ってしまうことがあります。交互の背景色があると、視線が同じ行に留まりやすくなります。行数が少ない（3行以下）場合はストライプなしでも問題ありません。

キャプションでテーブルの文脈を伝える
<caption>要素はテーブルのタイトルです。視覚的にも意味的にも「このテーブルは何のデータか」を明示します。スクリーンリーダーのユーザーにとっては、テーブルに到達した瞬間に内容を把握できる重要な手がかりです。

コード解説


<div class="table-wrapper">

  
  <table class="data-table">

    
    <caption>社員一覧</caption>

    
    <thead>
      <tr>
        
        <th scope="col">名前</th>
        <th scope="col">部署</th>
        <th scope="col">役職</th>
        <th scope="col" class="col-number">入社年</th>
        <th scope="col" class="col-email">メールアドレス</th>
      </tr>
    </thead>

    
    <tbody>
      <tr>
        <td>田中 太郎</td>
        <td>エンジニアリング</td>
        <td>シニアエンジニア</td>
        <td class="col-number">2018</td>
        <td class="col-email">tanaka.taro@example.com</td>
      </tr>
      
    </tbody>

    
    <tfoot>
      <tr>
        <td colspan="3">合計社員数</td>
        <td class="col-number">7名</td>
        <td></td>
      </tr>
    </tfoot>

  </table>
</div>
/* === テーブルラッパー ===
   横スクロール対応のために必須。
   テーブルが画面幅を超えた場合、ラッパーが
   スクロールバーを表示して内容を見られるようにする */
.table-wrapper {
  width: 100%;
  overflow-x: auto;   /* 横にはみ出したらスクロール */
  -webkit-overflow-scrolling: touch;  /* iOS慣性スクロール */
  border: 1px solid var(--color-border);
  border-radius: var(--radius-md);
}

/* === テーブル本体 === */
.data-table {
  width: 100%;

  /* border-collapse: collapse → セルの隙間を消して、
     ボーダーを1本に重ねて表示する。
     もう一つの方法 border-spacing は隙間を空けるが、
     モダンなUIでは collapse がほぼ標準 */
  border-collapse: collapse;
  font-size: var(--text-sm);
  line-height: 1.5;
}

/* === キャプション（テーブルタイトル） === */
.data-table caption {
  padding: var(--space-3) var(--space-4);
  font-weight: var(--font-semibold);
  text-align: left;
  caption-side: top;  /* top=上部、bottom=下部 */
}

/* === ヘッダーセル ===
   scope="col" と合わせて、アクセシビリティを確保する */
.data-table thead th {
  padding: var(--space-3) var(--space-4);
  font-weight: var(--font-semibold);
  text-align: left;
  white-space: nowrap;       /* ヘッダーは折り返さない */
  vertical-align: middle;    /* 上下中央揃え */
  border-bottom: 2px solid var(--color-border);  /* 太い線で区切り */
}

/* === データセル === */
.data-table tbody td {
  padding: var(--space-3) var(--space-4);
  vertical-align: middle;    /* セルの内容を上下中央に配置 */
  border-bottom: 1px solid var(--color-border);
}

/* === ゼブラストライプ ===
   :nth-child(even) → 偶数行に薄い背景色を付ける。
   広いテーブルで行を目で追いやすくする効果がある。
   odd を使えば奇数行に適用できる */
.data-table tbody tr:nth-child(even) {
  background-color: var(--color-bg-secondary);
}

/* === ホバーハイライト ===
   マウスを乗せた行を強調して、今見ている行を明確にする */
.data-table tbody tr:hover {
  background-color: hsla(222, 80%, 60%, 0.08);
}

/* === 数値列の右揃え ===
   数字を右揃えにすると桁が揃い、大小比較がしやすくなる。
   金額・年数・個数など数値データには必ず適用する */
.col-number {
  text-align: right;
}

/* === メール列の折り返し防止 ===
   メールアドレスは途中改行すると読みにくいため、
   改行を禁止して横スクロールで対応する */
.col-email {
  white-space: nowrap;
}

/* === フッター行 ===
   合計やサマリーを表示する行。
   border-top を太くしてデータ行との境界を明確にする */
.data-table tfoot td {
  padding: var(--space-3) var(--space-4);
  font-weight: var(--font-semibold);
  border-top: 2px solid var(--color-border);
}
