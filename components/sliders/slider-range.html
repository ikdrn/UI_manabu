スライダー・カルーセル

レンジスライダー

値の範囲を指定するinput[type="range"]のスタイリング。ブラウザデフォルト、カスタムスタイル、そして2つのつまみで範囲を選択するデュアルレンジの3段階で学びます。

プレビュー

1. ブラウザデフォルト
音量 50
2. カスタムスタイル
不透明度 80%
3. デュアルレンジ（価格フィルター）
¥2,000 〜 ¥8,000
¥0 ¥10,000

設計の意図

なぜレンジスライダーのカスタマイズは難しいのか？
input[type="range"]はブラウザごとに内部構造（シャドウDOM）が異なります。WebKit系は::-webkit-slider-thumb、Firefoxは::-moz-range-thumbと、ベンダープレフィックス付きの疑似要素で個別にスタイルを記述する必要があります。

トラックの塗りつぶし問題
Firefoxには::-moz-range-progressで値の左側を塗れますが、WebKit系にはこの機能がありません。そのため、JavaScriptでlinear-gradientの割合を動的に更新する手法が一般的です。

デュアルレンジの実装アプローチ
HTML標準にはデュアルレンジ入力が存在しないため、2つのrange inputを重ねて配置します。pointer-events: noneでトラッククリックを無効化し、つまみだけpointer-events: allにすることで、2つのつまみを独立して操作できます。

コード解説

<!-- 1. 基本のレンジ入力 -->
<!-- min/max → 値の範囲を指定 -->
<!-- value → 初期値 -->
<!-- aria-label → スクリーンリーダー用のラベル -->
<input type="range" min="0" max="100" value="50"
       aria-label="音量">

<!-- 2. カスタムスタイル付きレンジ -->
<!-- class="range-styled" → appearance: none でデフォルトを消し、
     疑似要素でカスタマイズ -->
<input type="range" class="range-styled"
       min="0" max="100" value="80"
       aria-label="不透明度">

<!-- 3. デュアルレンジ（2つのinputを重ねる） -->
<div class="dual-range">
  <!-- 選択範囲の塗りつぶし表示 -->
  <div class="dual-range__fill"></div>

  <!-- 最小値のつまみ -->
  <input type="range" id="rangeMin"
         min="0" max="10000" value="2000" step="500"
         aria-label="最低価格">

  <!-- 最大値のつまみ -->
  <input type="range" id="rangeMax"
         min="0" max="10000" value="8000" step="500"
         aria-label="最高価格">
</div>
/* --- appearance: none でブラウザデフォルトを完全リセット --- */
.range-styled {
  -webkit-appearance: none;  /* WebKit系（Chrome, Safari, Edge） */
  appearance: none;          /* 標準プロパティ */
  width: 100%;
  height: 6px;               /* トラックの太さ */
  border-radius: 3px;        /* 角丸 */
  background: #e2e8f0;       /* トラックの色 */
  outline: none;
  cursor: pointer;
}

/* --- WebKit系: つまみ（サム）のカスタマイズ --- */
.range-styled::-webkit-slider-thumb {
  -webkit-appearance: none;  /* デフォルトのつまみを消す */
  width: 20px;
  height: 20px;
  border-radius: 50%;        /* 円形 */
  background: #3b82f6;       /* ブランドカラー */
  border: 3px solid white;   /* 白い縁取りで浮いて見える効果 */
  /* 影で立体感を出す */
  box-shadow: 0 1px 4px rgba(0, 0, 0, 0.2);
  cursor: pointer;
  /* ホバー時のスケールアニメーション */
  transition: transform 150ms, box-shadow 150ms;
}

.range-styled::-webkit-slider-thumb:hover {
  transform: scale(1.15);    /* 少し大きくして「掴める」感を出す */
  box-shadow: 0 2px 8px rgba(59, 130, 246, 0.3);
}

/* --- Firefox: つまみのカスタマイズ --- */
.range-styled::-moz-range-thumb {
  width: 20px;
  height: 20px;
  border-radius: 50%;
  background: #3b82f6;
  border: 3px solid white;
  box-shadow: 0 1px 4px rgba(0, 0, 0, 0.2);
  cursor: pointer;
}

/* --- Firefox: トラックの塗りつぶし（値の左側） --- */
.range-styled::-moz-range-progress {
  height: 6px;
  border-radius: 3px;
  background: #3b82f6;  /* 値の左側をブランドカラーで塗る */
}

/* === デュアルレンジ: 2つのinputを重ねる === */
.dual-range input[type="range"] {
  position: absolute;       /* 同じ位置に重ねる */
  width: 100%;
  background: transparent;  /* トラックを透明にする */
  pointer-events: none;     /* トラック上のクリックを無効化 */
}

.dual-range input[type="range"]::-webkit-slider-thumb {
  pointer-events: all;  /* つまみだけクリック可能にする */
  z-index: 2;           /* 上に表示 */
}
// === カスタムスタイル版: トラックの塗りつぶしを更新 ===
const styledRange = document.getElementById('styledRange');

styledRange.addEventListener('input', () => {
  const val = styledRange.value;
  // linear-gradient の割合を動的に変えて
  // 値の左側をブランドカラーで塗る
  styledRange.style.background =
    'linear-gradient(to right, #3b82f6 ' + val + '%, #e2e8f0 ' + val + '%)';
});

// === デュアルレンジ: 2つのつまみの値を連動 ===
const rangeMin = document.getElementById('rangeMin');
const rangeMax = document.getElementById('rangeMax');
const fill = document.getElementById('rangeFill');

function updateDualRange() {
  let min = parseInt(rangeMin.value);
  let max = parseInt(rangeMax.value);

  // 最小値が最大値を超えないように制約
  if (min > max) {
    // どちらのinputが操作されたかで調整先を変える
    const temp = min;
    min = max;
    max = temp;
    rangeMin.value = min;
    rangeMax.value = max;
  }

  // 塗りつぶしバーの位置と幅を計算
  const total = rangeMax.max - rangeMin.min;
  const leftPercent = ((min - rangeMin.min) / total) * 100;
  const rightPercent = ((max - rangeMin.min) / total) * 100;

  // CSSのleftとwidthで塗りつぶし範囲を表現
  fill.style.left = leftPercent + '%';
  fill.style.width = (rightPercent - leftPercent) + '%';

  // 価格表示を更新
  // toLocaleString → 数値を3桁カンマ区切りにする
  document.getElementById('priceMin').textContent =
    '¥' + min.toLocaleString();
  document.getElementById('priceMax').textContent =
    '¥' + max.toLocaleString();
}

// input イベント → つまみを動かしている最中にリアルタイムで発火
rangeMin.addEventListener('input', updateDualRange);
rangeMax.addEventListener('input', updateDualRange);

// 初期表示
updateDualRange();

実運用でのエッジケース

ブラウザ間の見た目の違い

Chrome, Firefox, Safariでそれぞれ見た目が異なります。特にトラックの塗りつぶしはFirefoxの::-moz-range-progressが便利ですが、WebKit系にはないため、JSでbackgroundを動的に更新する手法が必要です。

デュアルレンジのつまみが重なる場合

上のデュアルレンジで、2つのつまみを同じ位置まで近づけてみてください。つまみが重なった時にどちらが上に来るか、z-indexの管理が重要になります。

キーボード操作

Tabキーでスライダーにフォーカスし、左右矢印キーで値を変更できます。ブラウザ標準のinput[type="range"]はキーボード操作が自動でサポートされています。
