カード

統計カード

ダッシュボードでKPI（重要指標）を一覧表示するためのカード。数値を主役にし、トレンド（増減）で文脈を与えることで、一目でビジネスの状況を把握できます。

プレビュー

総ユーザー数 12,847 12.5%
月間売上 ¥3,284,000 8.2%
コンバージョン率 3.24% 2.1%
直帰率 42.8% 0.0%

設計の意図

数値を主役にする（フォントサイズの階層）
ラベル（小さい）→ 数値（大きい・太い）→ トレンド（小さい）の3層構造。数値を最も目立たせることで、ダッシュボードを開いた瞬間にKPIが目に入る設計です。

トレンドで文脈を与える
「3,284,000円」という数値だけでは良いのか悪いのか判断できません。「↑ 8.2%」というトレンドがあることで、前期比で成長しているという文脈が加わり、数値の意味が明確になります。

色 + 形でアクセシビリティを確保
上昇＝緑、下降＝赤だけでは色覚多様性のユーザーに伝わりません。矢印の方向（↑↓→）を併用することで、色に頼らずトレンドの方向を伝えています。

カードの均一サイズで視覚的リズムを作る
全てのカードが同じ高さ・幅になることで、ダッシュボード全体にリズム感が生まれ、素早くスキャンしやすくなります。

/* --- ダッシュボード用グリッドレイアウト ---
   display: grid で子要素をタイル状に並べる。
   repeat(auto-fit, minmax(220px, 1fr)) は
   「最小220px、余りは均等配分」の意味。
   画面幅に応じて自動的にカラム数が変わるレスポンシブグリッド */
.stats-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 1rem;
}

/* --- 統計カード本体 --- */
.stat-card {
  background-color: #ffffff;
  border: 1px solid #e5e7eb;
  border-radius: 12px;
  padding: 1.25rem;

  /* flex-direction: column → ラベル・数値・トレンドを縦に積む */
  display: flex;
  flex-direction: column;
  gap: 0.5rem;
}

/* --- カードラベル（指標名） ---
   小さく控えめに。数値の脇役 */
.stat-label {
  font-size: 0.75rem;
  font-weight: 500;
  color: #6b7280;
}

/* --- 数値（メインの値） ---
   カードの主役。最も大きく太い */
.stat-value {
  font-size: 1.5rem;
  font-weight: 700;
  color: #111827;
  line-height: 1.2;

  /* font-variant-numeric: tabular-nums →
     全ての数字を同じ幅にする。
     「1」と「0」の幅が揃い、
     数値が変動してもレイアウトがガタつかない。
     ダッシュボードの数値表示には必須の指定 */
  font-variant-numeric: tabular-nums;
}

/* --- トレンドの色分け --- */
/* 上昇 → 緑: ポジティブな変化 */
.stat-trend--up { color: #16a34a; }

/* 下降 → 赤: ネガティブな変化 */
.stat-trend--down { color: #dc2626; }

/* 横ばい → グレー: 変化なし */
.stat-trend--neutral { color: #6b7280; }

/* --- CSS三角形（borderトリック） ---
   width/heightを0にして、borderだけで三角形を描く。
   上向き矢印: border-bottomだけ色を付ける
   下向き矢印: border-topだけ色を付ける */
.stat-trend__arrow {
  display: inline-block;
  width: 0;
  height: 0;
  border-left: 4px solid transparent;
  border-right: 4px solid transparent;
}

.stat-trend--up .stat-trend__arrow {
  border-bottom: 5px solid currentColor;
}

.stat-trend--down .stat-trend__arrow {
  border-top: 5px solid currentColor;
}
