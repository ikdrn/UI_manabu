設計の意図

視覚的な階層で意思決定を誘導する（おとり効果）
中央のプランを transform: scale(1.05) で拡大し、ブランドカラーの枠線と「おすすめ」バッジで強調しています。人は3つの選択肢があると真ん中を選びやすい傾向があり（中心効果）、さらに視覚的に目立たせることで推奨プランへの誘導を強めます。

機能比較で「損をしたくない」心理に訴える
ベーシックプランに ✕ マークの機能を表示することで、「無料だと使えない機能がある」ことを明示しています。これは「損失回避」の心理を活用したデザインパターンです。有料プランの ✓ と対比させることで、アップグレードの価値を直感的に伝えます。

価格のタイポグラフィで「安く見せる」工夫
金額の数字を最大サイズにし、「/月」を小さく控えめに表示しています。ユーザーの視線が数字に集中するため、期間あたりのコストより「金額そのもの」が印象に残ります。通貨記号も数字より小さくすることで、数字の存在感を最大化しています。

/* === カードコンテナ === */
.pricing-container {
  /* display: flex → 子要素（カード）を横並びにする */
  display: flex;
  gap: 24px;

  /* align-items: center → scale で拡大されたカードも
     上下中央に揃える */
  align-items: center;
  justify-content: center;

  /* flex-wrap: wrap → 画面幅が足りない時に折り返す */
  flex-wrap: wrap;
}

/* === 個別のカード === */
.pricing-card {
  /* position: relative → バッジ（absolute）の配置基準になる。
     これがないとバッジはページ左上に飛んでしまう */
  position: relative;

  /* overflow: hidden → バッジがカードの角丸からはみ出さない */
  overflow: hidden;

  background: white;
  border: 2px solid #e5e7eb;
  border-radius: 16px;
  padding: 32px 24px;
  width: 280px;
  text-align: center;
  transition: box-shadow 250ms, transform 250ms;
}

/* === 推奨プラン — 視覚的な強調 === */
.pricing-card--recommended {
  /* transform: scale(1.05) → 5%拡大で「これが主役」と伝える。
     1.05は目立つが違和感がない絶妙な値 */
  transform: scale(1.05);

  /* ブランドカラーの枠線で特別感を演出 */
  border-color: hsl(222, 80%, 50%);

  /* 強い影で「浮いている」ように見せる */
  box-shadow: 0 8px 24px hsla(220, 15%, 10%, 0.12);

  /* z-index → 拡大されたカードを手前に表示 */
  z-index: 1;
}

/* === 「おすすめ」バッジ === */
.pricing-badge {
  /* position: absolute → カード内の好きな位置に配置できる */
  position: absolute;
  top: 0;
  left: 0;
  right: 0;
  background: hsl(222, 80%, 50%);
  color: white;
  font-size: 12px;
  font-weight: 700;
  padding: 4px 16px;
}

/* === 機能リスト — カスタム箇条書き === */
.pricing-features {
  /* list-style: none → デフォルトの「・」を消す */
  list-style: none;
  padding: 0;
}

.pricing-features li {
  padding-left: 24px;
  position: relative;
}

/* ::before 擬似要素でチェックマークを追加 */
.pricing-features li::before {
  /* content: "✓" → CSSだけでテキストを挿入できる。
     装飾目的の記号はHTMLでなくCSSで追加するのがベスト */
  content: "✓";
  position: absolute;
  left: 0;
  color: hsl(152, 60%, 40%);
  font-weight: 700;
}

/* 利用不可の機能は ✕ マークとグレー色に */
.pricing-features li.is-unavailable::before {
  content: "✕";
  color: #9ca3af;
}

/* === レスポンシブ: モバイルで縦並びに === */
@media (max-width: 768px) {
  .pricing-container {
    /* flex-direction: column → 横並びから縦並びに切り替え */
    flex-direction: column;
  }

  .pricing-card { width: 100%; max-width: 400px; }

  /* モバイルでは scale を解除（縦並びでは不要） */
  .pricing-card--recommended { transform: none; }
}
