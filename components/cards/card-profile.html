設計の意図

カードはなぜ「スキャナブル」なのか？
カードは情報を視覚的な境界（影と角丸）で区切ることで、ユーザーが一つの単位として認識できます。人物情報をカードにまとめると、一覧から目当ての人をすばやく見つけられます。

アバターが「視覚的なアンカー」になる理由
人間の脳は顔（または顔を連想させる円形）に自然と注意を向けます。アバターをカードの上部中央に配置し、ヘッダーとボディの境界にまたがらせることで、カード全体の視覚的な「重心」を作っています。

情報の階層：ビジュアル → 名前 → 役職 → 詳細
最も重要な「誰か」を視覚（アバター）と名前で素早く伝え、次に「何をしている人か」（役職）、最後に「もっと知りたい」人向けの詳細（自己紹介・SNSリンク）を配置します。この順番がユーザーの自然な認知プロセスに合致します。

/* --- カード本体 --- */
.profile-card {
  width: 280px;
  background-color: var(--color-surface-raised);

  /* border-radius: 12px → 角を丸くしてカード感を出す。
     丸みは「まとまり」「親しみ」を感じさせる */
  border-radius: var(--radius-lg);

  /* box-shadow → カードに影を付けて「浮いている」ように見せる。
     影が深いほど、その要素が手前にあるように感じられる。
     これを「エレベーション（高さ）」と呼ぶ */
  box-shadow: var(--shadow-md);

  /* overflow: hidden → カードからはみ出す部分を隠す。
     ヘッダーの角が border-radius に沿って切り取られる */
  overflow: hidden;
}

/* --- ヘッダーバナー --- */
.profile-card__header {
  height: 100px;

  /* linear-gradient(角度, 色1, 色2) → 2色のグラデーション。
     135deg は左上から右下への斜めグラデーション。
     画像を使わずに視覚的なアクセントを作れる */
  background: linear-gradient(
    135deg,
    var(--color-brand-400),
    var(--color-brand-700)
  );
}

/* --- アバター（丸いイニシャルアイコン） --- */
.profile-card__avatar {
  width: 80px;
  height: 80px;

  /* border-radius: 50% → 正方形を完全な円に変える。
     「50%」は要素の幅・高さの半分 = 半径。
     つまり4つの角が全て円弧になり、真円になる。
     ★ width と height が違う値だと楕円になるので注意 */
  border-radius: 50%;

  /* margin: 0 auto → 左右を自動マージンにしてブロックを中央揃え。
     text-align: center は inline 要素用、
     margin: 0 auto は block 要素用の中央揃え */
  margin: 0 auto;

  /* margin-top: -40px → 負（マイナス）のマージン。
     通常マージンは要素を離すが、負の値は要素を引き寄せる。
     アバターの高さ80pxの半分 = 40pxだけ上に引き上げて、
     ヘッダーバナーに半分重なるように配置する。
     これがヘッダーとボディを「つなぐ」視覚的なアンカーになる */
  margin-top: -40px;

  /* 白い枠線でアバターをヘッダー背景から浮かせる */
  border: 4px solid var(--color-surface-raised);

  /* --- CSSだけでイニシャルを中央に表示する ---
     display: grid + place-items: center の組み合わせは
     縦横中央揃えの最もシンプルな書き方。
     flexboxで同じことをするには3つのプロパティが必要:
       display: flex;
       align-items: center;
       justify-content: center;
     gridなら2行で済む */
  display: grid;
  place-items: center;

  background-color: var(--color-brand-500);
  color: white;
  font-size: var(--text-xl);
  font-weight: var(--font-bold);
}

/* --- もし画像のアバターを使う場合 ---
   .profile-card__avatar-img {
     width: 100%;
     height: 100%;
     border-radius: 50%;

     object-fit: cover → 画像のアスペクト比（縦横比）を維持したまま
     要素全体を覆うようにリサイズ＆トリミングする。
     顔写真が歪まず、必ず円形の枠にフィットする。

     比較:
     - object-fit: contain → 画像全体が見えるが、余白ができる
     - object-fit: cover → 余白なしだが、端が切れることがある
     - object-fit: fill → 余白なしだが、画像が歪む（デフォルト）
   } */

/* --- カードボディ --- */
.profile-card__body {
  padding: 0 var(--space-6) var(--space-6);

  /* text-align: center → カード内のテキストを全て中央揃えにする。
     プロフィールカードはアバターを中心にした「左右対称」レイアウト。
     対称性は「安定感」と「フォーマルさ」を感じさせる */
  text-align: center;
}

/* --- 自己紹介文（行数制限） --- */
.profile-card__bio {
  /* -webkit-line-clamp で表示行数を制限し、
     超過分を「…」で省略する。
     3つのプロパティをセットで指定する必要がある */
  display: -webkit-box;
  -webkit-line-clamp: 3;        /* 最大3行まで */
  -webkit-box-orient: vertical; /* 縦方向にボックスを並べる */
  overflow: hidden;             /* はみ出た部分を隠す */
}

/* --- ソーシャルリンク --- */
.profile-card__socials {
  display: flex;
  justify-content: center;
  gap: var(--space-3);

  /* flex-wrap: wrap → リンクが多い場合に自動的に折り返す。
     wrap がないと要素が無理に1行に収まろうとして
     カードからはみ出す可能性がある */
  flex-wrap: wrap;
}

/* 各ソーシャルリンクアイコン */
.profile-card__social-link {
  width: 36px;
  height: 36px;
  border-radius: 50%;
  display: inline-flex;
  align-items: center;
  justify-content: center;
  background-color: var(--color-neutral-100);
  color: var(--color-neutral-600);
  text-decoration: none;
  font-size: var(--text-xs);
  font-weight: var(--font-semibold);
  text-transform: uppercase;
}

実運用でのエッジケース

非常に長い名前

overflow-wrap: break-word により、長い名前もカード内で折り返される。レイアウトが崩れない。
