設計の意図

F字パターンの視線誘導
人はWebページをF字型にスキャンします。画像が最初に視線を捉え → タイトルで内容を判断 → 抜粋で詳細を確認 → フッターで信頼性を補強、という流れです。

line-clampによるテキスト制御
タイトルは2行、抜粋は3行に制限。カードの高さが揃い、一覧ページで美しいグリッドを維持できます。テキストが長すぎても「...」で省略されます。

flex: 1による柔軟なレイアウト
抜粋テキストに`flex: 1`を指定することで、内容の長さに関わらずフッター（著者情報）が常にカードの底に押し下げられます。

コード解説

.card-grid {
  /* repeat(auto-fill, minmax(280px, 1fr)) →
     最小280px、最大1frで自動的に列数が決まる魔法のグリッド。
     画面幅に応じて2列→3列→4列と自動調整される */
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 24px;
}

.blog-card {
  display: flex;
  flex-direction: column; /* 縦方向に要素を並べる */
  overflow: hidden; /* 角丸の外にはみ出す画像を隠す */
  border-radius: 12px;
  transition: box-shadow 250ms, transform 250ms;
}

.blog-card:hover {
  box-shadow: 0 8px 24px hsla(220,15%,10%,0.12);
  transform: translateY(-2px); /* わずかに浮き上がる → クリック可能を示唆 */
}

.card-image {
  /* aspect-ratio: 16/9 → 横長の比率を固定。
     画像の高さが内容に依存しないため、カードの高さが揃う */
  aspect-ratio: 16 / 9;
}

.card-title {
  /* -webkit-line-clamp: 2 → テキストを2行に制限し、超えた分は ... で省略 */
  display: -webkit-box;
  -webkit-line-clamp: 2;
  -webkit-box-orient: vertical;
  overflow: hidden;
}

.card-excerpt {
  -webkit-line-clamp: 3; /* 抜粋は3行まで */
  flex: 1; /* 残りスペースを埋める → フッターを底に押し下げる */
}

.card-avatar {
  width: 32px; height: 32px;
  border-radius: 50%; /* 正円にする */
  /* place-items: center → grid内の要素を縦横中央に配置 */
  display: grid;
  place-items: center;
}
