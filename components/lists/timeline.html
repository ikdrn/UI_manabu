設計の意図

なぜ時系列表現にタイムラインを使うのか？
縦方向に時間の流れを表現するのは人間にとって直感的です。上から下へ読む自然な流れと、時間の経過を一致させることで、ユーザーは意識せずに情報の前後関係を理解できます。

縦線とドットによる視覚的接続
縦線はイベント同士が「つながっている」ことを視覚的に示します。ドットマーカーは各イベントの「位置」を明確にし、線上のどこにイベントがあるかを示します。この2つの要素が、個別のカードをひとつの物語として結びつけます。

デスクトップでの左右交互配置
全てのカードを片側に並べると、縦に長くなり視覚的に単調になります。左右交互に配置することで、ジグザグに視線が動き、各イベントに注意が向きやすくなります。

色によるステータスの即時伝達
緑（完了）・青（進行中）・グレー（未来）の色分けは、テキストを読む前にステータスを把握できるようにします。ただし色だけに頼らず、テキストバッジも併用してアクセシビリティを確保しています。

/* --- タイムラインコンテナ ---
   position: relative → ::before（縦線）の絶対配置の基準になる */
.timeline {
  position: relative;
  padding: 24px 0;
}

/* --- 中央の縦線 ---
   ::before擬似要素 → HTMLに要素を追加せず、CSSだけで装飾要素を作る。
   content: "" → 空のコンテンツを指定。これがないと擬似要素は表示されない。
   position: absolute → 通常のレイアウトフローから外れ、親要素を基準に配置。
   left: 50% + transform → コンテナの正確な中央に配置。
   top: 0, bottom: 0 → 親要素の高さいっぱいに伸びる */
.timeline::before {
  content: "";
  position: absolute;
  left: 50%;
  transform: translateX(-50%);
  top: 0;
  bottom: 0;
  width: 2px;
  background-color: #d1d5db;
}

/* --- タイムラインアイテム ---
   width: 50% → デスクトップでは片側半分だけ使う */
.timeline-item {
  position: relative;
  width: 50%;
  margin-bottom: 32px;
}

/* --- :nth-child(odd) → 1,3,5番目（奇数番目）に適用 ---
   左側に配置し、テキストを右寄せにする */
.timeline-item:nth-child(odd) {
  left: 0;
  text-align: right;
  padding-right: 40px;
}

/* --- :nth-child(even) → 2,4,6番目（偶数番目）に適用 ---
   left: 50% → 右側に配置。テキストは左寄せ */
.timeline-item:nth-child(even) {
  left: 50%;
  text-align: left;
  padding-left: 40px;
}

/* --- ドットマーカー ---
   ::after擬似要素 → 縦線上にステータスを示す丸い点を作る。
   border-radius: 50% → 正方形の要素を完全な円にする。
   z-index: 1 → 縦線（::before）の上に表示 */
.timeline-item::after {
  content: "";
  position: absolute;
  top: 8px;
  width: 16px;
  height: 16px;
  border-radius: 50%;
  border: 3px solid white;
  z-index: 1;
}

/* 奇数アイテム → ドットを右端（縦線上）に配置 */
.timeline-item:nth-child(odd)::after {
  right: -8px;
}

/* 偶数アイテム → ドットを左端（縦線上）に配置 */
.timeline-item:nth-child(even)::after {
  left: -8px;
}

/* --- ステータス色 --- */
/* 完了: 緑 → 達成感・安心感を伝える色 */
.timeline-item--completed::after {
  background-color: #22c55e;
  box-shadow: 0 0 0 2px #22c55e;
}

/* 進行中: 青 → アクティブ・行動中を示す色 */
.timeline-item--current::after {
  background-color: #3b82f6;
  box-shadow: 0 0 0 2px #3b82f6;
}

/* 未来: グレー → 未達・待機中を控えめに示す色 */
.timeline-item--future::after {
  background-color: #d1d5db;
  box-shadow: 0 0 0 2px #d1d5db;
}

/* ===== モバイル対応 =====
   @media (max-width: 768px) → 画面幅768px以下で適用。
   デスクトップの左右交互配置から、一列配置に切り替える。
   縦線を左端に移動し、全カードを右側に統一する */
@media (max-width: 768px) {
  .timeline::before {
    left: 20px;
    transform: none;
  }

  .timeline-item,
  .timeline-item:nth-child(odd),
  .timeline-item:nth-child(even) {
    width: 100%;
    left: 0;
    text-align: left;
    padding-left: 50px;
    padding-right: 0;
  }

  .timeline-item::after,
  .timeline-item:nth-child(odd)::after,
  .timeline-item:nth-child(even)::after {
    left: 12px;
    right: auto;
  }
}
