ボタン

ボタングループ / セグメンテッドコントロール

関連する複数の操作をひとまとめにし、視覚的にグループであることを示すパターン。セグメンテッドコントロールは排他選択（1つだけ選べる）、標準ボタングループは並列操作に使います。

プレビュー — セグメンテッドコントロール

プレビュー — 標準ボタングループ

設計の意図

グルーピングが有効な場面と逆効果な場面
関連する操作（例：テキストの左揃え・中央・右揃え）をグループにすると、ユーザーは選択肢の全体像を一目で把握できます。一方、性質の異なる操作（例：「保存」と「表示切替」）を無理にまとめると、かえって混乱を招きます。

セグメンテッドコントロール vs タブ
見た目は似ていますが、役割が異なります。タブは「コンテンツパネルを切り替える」（パネルA/B/Cが入れ替わる）。セグメンテッドコントロールは「同じコンテンツの表示方法を変える」（リスト表示⇄グリッド表示など）。使い分けを間違えるとユーザーの期待を裏切ります。

セグメントの最大数は2〜5個
6個以上になるとラベルが読みにくくなり、タップ領域も狭くなります。選択肢が多い場合はドロップダウンやタブバーへの切り替えを検討してください。

負のマージンでボーダーを共有する理由
隣り合うボタンにそれぞれ1pxのborderを付けると、境界部分が2px（二重線）になってしまいます。margin-left: -1px で1pxだけ重ねることで、見た目上1pxの区切り線を実現しています。

/* ===================================================================
   セグメンテッドコントロール — 排他選択用のボタングループ
   =================================================================== */

.segmented-control {
  /* display: flex → 子ボタンを横一列に並べる。
     flexboxはボタングループの基本レイアウト */
  display: flex;

  /* border-radius → グループ全体の外枠を角丸にする。
     個々のボタンの角丸は overflow: hidden で切り落とす */
  border-radius: var(--radius-md);

  /* overflow: hidden → 角丸の外にはみ出た子要素を隠す。
     これにより個々のボタンに角丸を指定しなくても
     グループ全体がきれいに丸まる */
  overflow: hidden;

  /* border → グループ全体を囲む枠線 */
  border: 1px solid var(--color-brand-500);

  /* width: fit-content → 中身の合計幅に合わせる。
     指定しないと親要素いっぱいに広がってしまう */
  width: fit-content;
}

.segmented-control__btn {
  /* flex: 1 → 各ボタンの幅を均等に分配する。
     3つのボタンなら各33.3%になる */
  flex: 1;

  padding: 10px 20px;
  font-size: var(--text-sm);
  font-weight: var(--font-semibold);
  line-height: 1;
  color: var(--color-brand-500);
  background-color: transparent;
  border: none;

  /* border-right → ボタン間の区切り線。
     親に overflow: hidden があるので角丸からはみ出ない */
  border-right: 1px solid var(--color-brand-500);

  cursor: pointer;
  transition: background-color 150ms, color 150ms;
  user-select: none;
  white-space: nowrap;
}

/* :last-child → 最後のボタンの右枠線を消す。
   親の右枠線と重複して2pxになるのを防ぐ */
.segmented-control__btn:last-child {
  border-right: none;
}

/* アクティブ（選択中）状態 → 塗りつぶしで選択を明示する */
.segmented-control__btn.is-active {
  background-color: var(--color-brand-500);
  color: white;
}

/* ===================================================================
   標準ボタングループ — 共有ボーダーで隣接させるパターン
   =================================================================== */

.btn-group {
  /* display: inline-flex → 横一列に並べつつ、
     グループ自体はインライン要素として他の要素と横に並べられる */
  display: inline-flex;
}

.btn-group__btn {
  padding: 10px 20px;
  font-size: var(--text-sm);
  font-weight: var(--font-semibold);
  line-height: 1;
  color: #555;
  background-color: white;
  border: 1px solid #d1d5db;
  cursor: pointer;
  transition: background-color 150ms, color 150ms, border-color 150ms;
  user-select: none;
  white-space: nowrap;

  /* border-radius: 0 → 全ボタンの角丸をリセット。
     端のボタンだけ後から角丸を付け直す */
  border-radius: 0;

  /* margin-left: -1px → 左に1pxずらして隣のボタンと枠線を重ねる。
     これで境界が2pxではなく1pxになる（ボーダー共有テクニック） */
  margin-left: -1px;

  /* position: relative → z-indexを効かせるために必要。
     hover時に手前に出して枠線が途切れないようにする */
  position: relative;
}

/* :first-child → 最初のボタンだけ左側を丸くする */
.btn-group__btn:first-child {
  border-radius: var(--radius-md) 0 0 var(--radius-md);
  margin-left: 0; /* 最初は左マージン不要 */
}

/* :last-child → 最後のボタンだけ右側を丸くする */
.btn-group__btn:last-child {
  border-radius: 0 var(--radius-md) var(--radius-md) 0;
}

/* hover時 → z-indexで手前に出し、枠線が隣に隠れないようにする */
.btn-group__btn:hover {
  background-color: #f3f4f6;
  z-index: 1;
}

/* アクティブ状態 → z-index: 2 で最前面にして
   ブランドカラーの枠線が確実に見えるようにする */
.btn-group__btn.is-active {
  background-color: var(--color-brand-500);
  color: white;
  border-color: var(--color-brand-500);
  z-index: 2;
}
// ===================================================================
// ボタングループ — ラジオボタン的な排他選択の実装
// ===================================================================

/**
 * initToggleGroup — グループ内のボタンにラジオボタン挙動を付与する
 *
 * 仕組み:
 * 1. クリックされたボタンに is-active クラスを付ける
 * 2. 兄弟ボタンから is-active を外す（排他選択）
 * 3. aria-pressed を更新してスクリーンリーダーにも状態を伝える
 *
 * @param {string} groupSelector — グループのCSSセレクタ
 * @param {string} btnSelector   — ボタンのCSSセレクタ
 */
function initToggleGroup(groupSelector, btnSelector) {
  // querySelectorAll → 該当するすべてのグループ要素を取得する
  const groups = document.querySelectorAll(groupSelector);

  groups.forEach(function(group) {
    // グループ内の全ボタンを取得する
    const buttons = group.querySelectorAll(btnSelector);

    buttons.forEach(function(btn) {
      // addEventListener('click', ...) → クリックイベントを登録する
      btn.addEventListener('click', function() {

        // --- 兄弟ボタンから選択状態を解除する ---
        buttons.forEach(function(sibling) {
          // classList.remove → CSSクラスを取り除く
          sibling.classList.remove('is-active');
          // setAttribute → HTML属性を書き換える
          sibling.setAttribute('aria-pressed', 'false');
        });

        // --- クリックされたボタンを選択状態にする ---
        // classList.add → CSSクラスを追加する
        btn.classList.add('is-active');
        btn.setAttribute('aria-pressed', 'true');
      });
    });
  });
}

// 初期化 — ページ読み込み後に実行する
// DOMContentLoaded → HTMLの解析が完了したタイミングで発火する
document.addEventListener('DOMContentLoaded', function() {
  // セグメンテッドコントロールの初期化
  initToggleGroup('.segmented-control', '.segmented-control__btn');

  // 標準ボタングループの初期化
  initToggleGroup('.btn-group', '.btn-group__btn');
});
