ボタン

アイコンボタン

アイコンだけ、またはアイコン＋テキストで操作を示すボタン。画像を使わず、CSSの::before/::after擬似要素とボーダートリックだけでアイコンを描く方法を学びます。

プレビュー

アイコンのみ（閉じる）
アイコン＋テキスト
テキスト＋末尾アイコン

設計の意図

アイコンのみボタンが許される場面
×（閉じる）、☰（メニュー）、⟨ ⟩（戻る・進む）など、世界中のユーザーが意味を理解できるアイコンに限ります。独自のアイコンをテキストなしで使うと、ユーザーは意味を推測しなければならず、操作を躊躇してしまいます。

アイコン＋テキストのほうが安全な理由
アイコンだけでは意味が曖昧な場合、テキストを添えることで確実に伝わります。たとえば下矢印だけでは「展開」なのか「ダウンロード」なのか分かりませんが、テキストがあれば迷いません。迷ったらテキストを付けましょう。

タッチターゲットの最小サイズ：44×44px
WCAG（Webアクセシビリティガイドライン）では、タッチ操作の最小サイズとして44×44pxを推奨しています。アイコンが小さく見えても、ボタン自体のクリック領域は44px以上を確保します。これにより、指が太い人や運動機能に制限がある人でも確実に押せます。

CSSだけでアイコンを描くメリット
画像ファイルやアイコンフォントを読み込む必要がなく、ページの読み込みが速くなります。また、currentColorを使えばテキスト色と連動するため、ダークモード対応も簡単です。

コード解説










/* === 基本スタイル === */
.btn-icon {
  /* display: inline-flex → アイコンとテキストを横に並べる */
  display: inline-flex;

  /* align-items: center → 縦方向の中央揃え。アイコンとテキストの高さが違っても中央に揃う */
  align-items: center;

  /* justify-content: center → 横方向の中央揃え。アイコンのみボタンで中央配置 */
  justify-content: center;

  /* gap: 8px → アイコンとテキストの間隔。marginで個別に指定するより
     gapで一括管理するほうが、要素の追加・削除に強い */
  gap: var(--space-2);

  padding: 10px 20px;
  font-size: var(--text-sm);
  font-weight: var(--font-semibold);
  line-height: 1;
  color: var(--color-brand-600);
  background-color: transparent;
  border: 1px solid var(--color-brand-300);
  border-radius: var(--radius-md);
  cursor: pointer;
}

/* === アイコン専用ボタン（正方形・円形） === */
.btn-icon--square {
  /* padding: 0 → 内側余白をなくし、サイズをwidth/heightだけで制御 */
  padding: 0;

  /* width: 44px → タッチターゲットの最小推奨サイズ（WCAG 2.5.5準拠） */
  width: 44px;

  /* aspect-ratio: 1 → 幅と高さを1:1にする。widthだけ指定すれば
     heightが自動で同じ値になる。レスポンシブ対応が楽 */
  aspect-ratio: 1;

  /* border-radius: 50% → 正方形を完全な円にする。
     50%はすべての角を最大限に丸くする特別な値 */
  border-radius: 50%;
}

/* === ×マーク（閉じるアイコン） === */
/* ::before と ::after で2本の線を描き、回転させて×を作る */
.icon-close {
  /* position: relative → 擬似要素をabsoluteで配置するための基準点 */
  position: relative;
}

.icon-close::before,
.icon-close::after {
  /* content: "" → 擬似要素の表示に必須。これがないと何も表示されない */
  content: "";

  /* position: absolute → 親の.icon-closeを基準に自由配置 */
  position: absolute;

  /* width: 18px, height: 2px → 細長い長方形で「線」を作る */
  width: 18px;
  height: 2px;

  /* background-color: currentColor → 親要素のcolorを自動的に継承。
     ホバー時の色変更やダークモードに自動対応する */
  background-color: currentColor;

  /* top: 50%, left: 50% → 一旦左上角を中央に置く（後でtranslateで補正） */
  top: 50%;
  left: 50%;
}

.icon-close::before {
  /* translate(-50%, -50%) → 自分自身の幅・高さの半分だけ戻して真の中央に
     rotate(45deg) → 45度回転で×の左上→右下の線 */
  transform: translate(-50%, -50%) rotate(45deg);
}

.icon-close::after {
  /* rotate(-45deg) → 反対方向に回転で×の右上→左下の線 */
  transform: translate(-50%, -50%) rotate(-45deg);
}

/* === 右矢印アイコン（ボーダートリック） === */
.icon-arrow-right::after {
  /* content: "" → 擬似要素を生成 */
  content: "";

  /* display: inline-block → 幅・高さを指定可能にする */
  display: inline-block;

  /* width/height: 8px → 小さな正方形を作る */
  width: 8px;
  height: 8px;

  /* border-right + border-bottom → 正方形の右辺と下辺だけに線を引く。
     これで「┘」の形ができる */
  border-right: 2px solid currentColor;
  border-bottom: 2px solid currentColor;

  /* rotate(-45deg) → 「┘」を-45度回転させると「>」（右矢印）になる。
     回転角度を変えるだけで上下左右どの矢印にもなる */
  transform: rotate(-45deg);

  /* flex-shrink: 0 → テキストが長くてもアイコンが潰れないようにする */
  flex-shrink: 0;
}

/* === 下矢印アイコン === */
.icon-arrow-down::after {
  content: "";
  display: inline-block;
  width: 8px;
  height: 8px;
  border-right: 2px solid currentColor;
  border-bottom: 2px solid currentColor;

  /* rotate(45deg) → 「┘」を45度回転させると「v」（下矢印）になる */
  transform: rotate(45deg);

  /* margin-top: -2px → 視覚的に中央に見えるよう微調整。
     回転した分だけ重心がずれるため補正する */
  margin-top: -2px;
  flex-shrink: 0;
}

実運用でのエッジケース

非常に小さい画面（320px幅）

小さい画面ではアイコンのみボタンでスペースを節約できる。ただしaria-labelを忘れずに。

RTL（右から左）への配慮

RTL言語では矢印の向きを反転させる必要がある。transform: scaleX(-1)や[dir="rtl"]セレクタを使って対応する。

長いテキスト＋アイコン

テキストが長い場合は折り返しを許可するが、アイコンはflex-shrink: 0で潰れないようにする。
