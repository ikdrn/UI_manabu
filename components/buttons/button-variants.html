ボタン

ボタンバリエーション

同じボタンでも「視覚的な重み」を変えることで、操作の重要度を直感的に伝えます。4つのバリエーションの使い分けを学びます。

プレビュー — 4つの視覚的重み

実際の使用例 — ダイアログ

この記事を削除しますか？

この操作は取り消せません。

設計の意図

視覚的重みの階層
塗りつぶし（Primary） > 枠線あり（Secondary） > テキストのみ（Ghost）。背景色の面積が大きいほど目立ち、重要度が高いことを示します。

色で危険度を示す
削除・解約など元に戻せない操作は赤系（Danger）で警告します。ブランドカラーとは別系統の色を使うことで、「通常の操作とは性質が違う」ことを伝えます。

使い分けガイド

種類用途例
Primary画面の主要アクション（1画面に1つ）保存、送信、購入
Secondary補助的だが重要な操作下書き保存、詳細を見る
Ghost控えめな操作・キャンセルキャンセル、閉じる、戻る
Danger破壊的・元に戻せない操作削除、解約、リセット

コード解説

/* すべてのボタンの共通スタイル（ベース） */
.btn {
  display: inline-flex;
  align-items: center;
  padding: 10px 20px;
  font-weight: 600;
  /* border: 2px solid transparent → 枠線ありの時とサイズを揃えるため、
     透明な枠線を常にセットしておく（枠線分のズレを防ぐ） */
  border: 2px solid transparent;
  border-radius: 8px;
  cursor: pointer;
  transition: all 150ms;
}

/* プライマリ — 塗りつぶしで最も目立つ */
.btn--primary {
  color: white;
  /* background-colorで面を塗ることで視覚的な重みが最大になる */
  background-color: var(--color-brand-500);
  /* border-colorもbackgroundと同じにして統一感を出す */
  border-color: var(--color-brand-500);
}

/* セカンダリ — 枠線のみで控えめに */
.btn--secondary {
  color: var(--color-brand-600);
  /* 背景を透明にすることで、プライマリより視覚的重みが軽い */
  background-color: transparent;
  /* 枠線でボタンの形を認識させる */
  border-color: var(--color-brand-300);
}

/* ゴースト — 枠線も背景もなく最も控えめ */
.btn--ghost {
  color: var(--color-neutral-600);
  background-color: transparent;
  /* 枠線も透明 → テキストリンクに近い軽さ */
  border-color: transparent;
}
.btn--ghost:hover {
  /* ホバーで薄い背景を出して「ボタンである」ことを示す */
  background-color: var(--color-neutral-100);
}

/* デストラクティブ — 赤で危険を示す */
.btn--danger {
  color: white;
  /* 赤系のerror色を使い、「通常操作とは違う」ことを視覚的に伝える */
  background-color: var(--color-state-error);
  border-color: var(--color-state-error);
}
