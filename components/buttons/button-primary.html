ボタン

プライマリボタン

画面の中で最も重要な操作を示すボタン。1画面に1つだけ置くのが原則で、ユーザーの視線と行動を導く「主役」です。

プレビュー

全幅ボタン

設計の意図

なぜプライマリボタンはブランドカラーを使うのか？
プライマリボタンは「次にしてほしい操作」を示します。ブランドカラーを使うことで、ページ内の他の要素と明確に差別化し、ユーザーの視線を自然に誘導します。

「1画面に1つだけ」の原則
プライマリボタンが複数あると、どれが最も重要かユーザーが判断できなくなります。主要な操作以外は、後で学ぶ「セカンダリ」や「ゴースト」スタイルのボタンを使います。

hover → active の段階的フィードバック
「乗せた」「押した」「離した」を色の変化とわずかな縮小で伝えます。この触覚的なフィードバックが、物理的なボタンを押す感覚を画面上で再現します。

コード解説














.btn {
  /* display: inline-flex → 横並びにしつつ、中身を柔軟に配置できる箱にする。
     後でアイコン+テキストを並べる時にも使える万能な指定 */
  display: inline-flex;

  /* align-items: center → flexの子要素を縦方向の中央に揃える。
     テキストの高さが違っても中心が揃う */
  align-items: center;

  /* justify-content: center → flexの子要素を横方向の中央に揃える。
     全幅ボタンでテキストが真ん中にくる */
  justify-content: center;

  /* gap: 8px → flex内の子要素間のスペース。
     アイコンとテキストの間隔を確保する */
  gap: var(--space-2);

  /* padding: 10px 20px → 上下10px、左右20pxの内側余白。
     クリックできる領域を確保する（最低44px以上が推奨） */
  padding: 10px 20px;

  /* font-size → 文字の大きさ。14px相当 */
  font-size: var(--text-sm);

  /* font-weight: 600 → やや太字。ボタンのテキストは通常より太くして
     「これは操作できる要素だ」と視覚的に伝える */
  font-weight: var(--font-semibold);

  /* line-height: 1 → 行間をなくす。ボタン内のテキストは1行なので、
     余分な上下スペースを消す */
  line-height: 1;

  /* color: white → テキストを白に。濃い背景色との対比で読みやすくする */
  color: white;

  /* background-color → ブランドカラーで塗りつぶし。
     これが「主役のボタン」であることを示す */
  background-color: var(--color-brand-500);

  /* border: none → ブラウザデフォルトの枠線を消す */
  border: none;

  /* border-radius: 8px → 角を丸くする。角丸は「クリックできる」印象を与え、
     直角より親しみやすい見た目になる */
  border-radius: var(--radius-md);

  /* cursor: pointer → マウスカーソルを指マークにする。
     「これは押せますよ」とユーザーに伝える */
  cursor: pointer;

  /* transition → 色や影の変化をなめらかにする。150msは瞬時だけど
     カクカクしない絶妙な速さ */
  transition: background-color 150ms,
              box-shadow 150ms,
              transform 150ms;

  /* user-select: none → テキストを選択できなくする。
     ボタンのテキストを誤って選択するのを防ぐ */
  user-select: none;

  /* white-space: nowrap → テキストを折り返さない。
     ボタンのテキストが2行になるのを防ぐ */
  white-space: nowrap;
}

/* :hover → マウスを乗せた時のスタイル */
.btn:hover {
  /* より濃い色に変えて「反応している」ことを示す */
  background-color: var(--color-brand-600);

  /* box-shadow → ボタンの下に影を落として「浮き上がった」感覚を出す。
     hslaのaは透明度（0.3 = 30%の不透明度） */
  box-shadow: 0 2px 8px hsla(222, 80%, 50%, 0.3);
}

/* :active → クリックした瞬間のスタイル */
.btn:active {
  /* さらに濃い色にして「押し込まれた」感覚を出す */
  background-color: var(--color-brand-700);

  /* transform: scale(0.98) → わずかに縮小して「押された」触感を再現 */
  transform: scale(0.98);

  /* 影を消して「沈み込んだ」表現に */
  box-shadow: none;
}

/* :focus-visible → キーボード操作時のフォーカス表示。
   マウスクリック時には出ないが、Tabキーで移動した時に出る */
.btn:focus-visible {
  outline: 2px solid var(--color-brand-500);
  outline-offset: 2px; /* ボタンから2px離して見やすくする */
}

/* :disabled → 無効状態。グレーにして操作不可を伝える */
.btn:disabled {
  background-color: var(--color-action-disabled);
  cursor: not-allowed; /* 禁止カーソルで「押せない」ことを強調 */
  box-shadow: none;
  transform: none;
}
