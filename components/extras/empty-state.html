空状態

コンテンツが存在しない場合に表示する空状態画面。「データなし」「検索結果なし」「エラー」の3パターンを、CSSイラストとメッセージ階層、CTAボタンで構成します。

プレビュー

まだデータがありません

最初のプロジェクトを作成して、タスク管理を始めましょう。

検索結果が見つかりません

「デザインシステム」に一致する結果がありませんでした。キーワードを変えてお試しください。

データの読み込みに失敗しました

サーバーとの通信中にエラーが発生しました。しばらくしてから再度お試しください。

設計の意図

空状態がなぜ重要なのか
「データがありません」とだけ表示されると、ユーザーは不安を感じたり、何をすべきか分からなくなります。イラスト、説明文、CTAボタンの3層構成で「状況の説明」と「次のアクション」を明確に伝えます。

CSSのみのイラスト
シンプルなイラストは::beforeと::afterの疑似要素、border、transformを組み合わせてCSSだけで描画できます。画像ファイルが不要なため読み込みが速く、色やサイズの変更も容易です。

メッセージ階層（タイトル → 説明 → CTA）
情報の重要度に応じてフォントサイズ、太さ、色を変えることで、ユーザーの視線を上から下に自然に誘導します。最後のCTAボタンが「次にすべきこと」を具体的に示します。

コード解説

<!-- 空状態カード → text-alignで中央揃え -->
<div class="empty-state">

  <!-- CSSイラスト → 疑似要素で描画 -->
  <div class="empty-illustration illust-no-data"></div>

  <!-- メッセージ階層: タイトル → 説明 → CTA -->
  <h3 class="empty-title">まだデータがありません</h3>
  <p class="empty-description">
    最初のプロジェクトを作成して、タスク管理を始めましょう。
  </p>

  <!-- CTAボタン → ユーザーの次のアクションを提示 -->
  <button class="empty-cta">プロジェクトを作成</button>
</div>

<!-- 検索結果なし -->
<div class="empty-state">
  <div class="empty-illustration illust-no-results">
    <span class="cross"></span> <!-- 虫眼鏡内の×マーク -->
  </div>
  <h3 class="empty-title">検索結果が見つかりません</h3>
  <p class="empty-description">キーワードを変えてお試しください。</p>
  <button class="empty-cta empty-cta--secondary">
    フィルターをクリア
  </button>
</div>

<!-- エラー状態 → 複数のCTAを提供 -->
<div class="empty-state">
  <div class="empty-illustration illust-error"></div>
  <h3 class="empty-title">読み込みに失敗しました</h3>
  <p class="empty-description">...</p>
  <div class="empty-actions">
    <button class="empty-cta empty-cta--error">再読み込み</button>
    <button class="empty-cta empty-cta--secondary">サポートに連絡</button>
  </div>
</div>
/* 空状態カード → 中央揃えのカードレイアウト */
.empty-state {
  text-align: center; /* すべてのコンテンツを中央揃え */
  padding: var(--space-8) var(--space-6);
  background: var(--color-bg-primary);
  border: 1px solid var(--color-border-secondary);
  border-radius: var(--radius-lg);
}

/* CSSイラスト: フォルダ → ::beforeで本体、::afterでタブを描画 */
.illust-no-data::before {
  content: '';
  position: absolute;
  bottom: 0;
  left: 50%;
  transform: translateX(-50%);
  width: 60px;
  height: 44px;
  background: var(--color-bg-tertiary);
  /* border-radius → 下だけ角丸にしてフォルダ形状に */
  border-radius: 0 0 var(--radius-md) var(--radius-md);
  border: 2px solid var(--color-border-secondary);
  border-top: none;
}

.illust-no-data::after {
  content: '';
  /* フォルダのタブ部分 → 上だけ角丸 */
  border-radius: var(--radius-sm) var(--radius-sm) 0 0;
}

/* CSSイラスト: 虫眼鏡 → ::beforeで円、::afterで柄 */
.illust-no-results::before {
  width: 40px;
  height: 40px;
  border: 3px solid var(--color-border-secondary);
  border-radius: 50%; /* 円形のレンズ部分 */
}

.illust-no-results::after {
  width: 4px;
  height: 24px;
  /* rotate(-45deg) → 斜めに傾けて持ち手を表現 */
  transform: rotate(-45deg);
}

/* CSSイラスト: 警告三角形 → borderで三角形を描画 */
.illust-error::before {
  /* border-left/right → 透明にして三角形の斜辺を作る
     border-bottom → 色付きにして三角形の底辺を作る */
  border-left: 36px solid transparent;
  border-right: 36px solid transparent;
  border-bottom: 60px solid #fef3c7; /* 黄色い三角形 */
}

.illust-error::after {
  content: '!'; /* 感嘆符で警告を表現 */
  font-size: 28px;
  font-weight: bold;
  color: #d97706;
}

/* メッセージ階層 — フォントサイズと色で重要度を区別 */
.empty-title {
  font-size: var(--text-base);    /* 最も大きく */
  font-weight: var(--font-semibold);
  color: var(--color-text-primary); /* 最も濃い色 */
}

.empty-description {
  font-size: var(--text-sm);       /* やや小さく */
  color: var(--color-text-secondary); /* やや薄い色 */
}

/* CTAボタン — 状態に応じたバリエーション */
.empty-cta {
  background: var(--color-brand-500); /* プライマリ */
}

.empty-cta--secondary {
  background: transparent;
  color: var(--color-brand-500);
  border: 1px solid var(--color-brand-300); /* アウトライン */
}

.empty-cta--error {
  background: #dc2626; /* 赤 → エラー時の再試行 */
}
