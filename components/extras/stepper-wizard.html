ステッパーウィザード

4ステップのフォームウィザード。ステップインジケーター、前へ/次へボタン、バリデーション付きで、複雑な入力フローを分割して案内します。

基本情報を入力してください
連絡先を入力してください
プランを選択してください
入力内容を確認してください

すべての情報が正しいことを確認したら「完了」ボタンを押してください。

設計の意図

ステップ分割で認知負荷を軽減
長いフォームを一度に表示すると離脱率が上がります。4つのステップに分割し、各ステップで求める情報を限定することで、ユーザーの心理的ハードルを下げます。

コネクターラインと進捗表示
ステップ円をコネクターラインで結び、完了済みのステップまでを色付きの進捗バーで示します。「あとどのくらいか」を視覚的に伝え、完了への動機付けを強化します。

reportValidity()によるバリデーション
ブラウザネイティブのreportValidity()メソッドを使い、required属性やtype属性（email, tel等）に基づく検証を行います。ライブラリ不要で基本的なバリデーションを実現できます。

/* パネルの切り替えアニメーション */
@keyframes panelFadeIn {
  from { opacity: 0; transform: translateX(16px); }
  to { opacity: 1; transform: translateX(0); }
}
let currentStep = 1;
const totalSteps = 4;
const prevBtn = document.getElementById('prevBtn');
const nextBtn = document.getElementById('nextBtn');
const progress = document.getElementById('stepperProgress');

nextBtn.addEventListener('click', () => {
  // 現在のパネルのバリデーション
  const currentPanel = document.querySelector(
    `.wizard-panel[data-panel="${currentStep}"]`
  );

  // reportValidity() → ブラウザネイティブのバリデーション
  // required属性やtype="email"などの制約を検証
  // 不正な値があるとブラウザがエラーメッセージを表示
  const inputs = currentPanel.querySelectorAll('input, select');
  let valid = true;
  inputs.forEach(input => {
    if (!input.reportValidity()) {
      valid = false;
    }
  });
  if (!valid) return;

  if (currentStep < totalSteps) {
    currentStep++;
    updateWizard();
  }
});

prevBtn.addEventListener('click', () => {
  if (currentStep > 1) {
    currentStep--;
    updateWizard();
  }
});

function updateWizard() {
  // パネルの表示切り替え
  document.querySelectorAll('.wizard-panel').forEach(panel => {
    panel.classList.toggle('active',
      panel.dataset.panel == currentStep);
  });

  // ステップインジケーターの更新
  document.querySelectorAll('.step').forEach(step => {
    const stepNum = parseInt(step.dataset.step);
    step.classList.remove('active', 'completed');
    if (stepNum === currentStep) {
      step.classList.add('active');
    } else if (stepNum < currentStep) {
      step.classList.add('completed');
    }
  });

  // プログレスバーの幅を更新
  // (currentStep - 1) / (totalSteps - 1) → 0%〜100%に変換
  const pct = ((currentStep - 1) / (totalSteps - 1)) * 100;
  progress.style.width = pct + '%';

  // ボタンの状態を更新
  prevBtn.disabled = currentStep === 1;
  nextBtn.textContent = currentStep === totalSteps ? '完了' : '次へ';
}
