アバタースタック

複数のユーザーアバターを重ねて表示するコンポーネント。イニシャルを使った円形アバターを負のマージンで重ね合わせ、残り人数を「+N」カウンターで表示します。

設計の意図

なぜ負のマージンで重ねるのか？
複数のアバターを横一列に表示すると場所を取りすぎます。負のmargin-leftで重ねることで、省スペースで「このタスクに関わる人たち」を一目で把握できます。白いボーダーが輪郭を明確にし、重なりの奥行きを表現します。

z-indexの順番が重要な理由
最初のアバターのz-indexを最も高く設定することで、左のアバターが右のアバターの上に重なります。これにより、リストの先頭が「最も目立つ」自然な視覚的階層が生まれます。

「+N」カウンターの役割
全員分のアバターを表示するとスペースを圧迫します。5人程度を表示して残りを「+3」のように示すことで、チームの規模感を伝えつつコンパクトにまとめます。

コード解説

<!-- アバタースタックのコンテナ -->
<div class="avatar-stack">

  <!-- 各アバター → data-tooltipで名前をホバー表示 -->
  <div class="avatar" data-tooltip="田中太郎">田</div>
  <div class="avatar" data-tooltip="佐藤花子">佐</div>
  <div class="avatar" data-tooltip="鈴木一郎">鈴</div>
  <div class="avatar" data-tooltip="高橋美咲">高</div>
  <div class="avatar" data-tooltip="伊藤健太">伊</div>

  <!-- +N カウンター → 表示しきれない残りの人数 -->
  <div class="avatar avatar--counter" data-tooltip="他3名">+3</div>
</div>

<!-- サイズバリエーション -->
<div class="avatar-stack avatar-stack--sm">...</div>
<div class="avatar-stack avatar-stack--lg">...</div>
/* アバタースタック → flexで横一列に配置 */
.avatar-stack {
  display: flex;
  align-items: center;
}

/* 個々のアバター → 円形にする */
.avatar {
  display: flex;
  align-items: center;
  justify-content: center;
  width: 40px;
  height: 40px;

  /* border-radius: 50% → 正方形を完全な円にする */
  border-radius: 50%;

  /* border: 3px solid white → 白い縁取りで重なりの境界を明確に */
  border: 3px solid white;

  font-size: var(--text-xs);
  font-weight: var(--font-semibold);
  color: white;

  /* position: relative → ツールチップの基準点にする */
  position: relative;
  cursor: pointer;
  transition: transform 150ms, margin 150ms;
}

/* 2番目以降のアバターに負のマージン → 重なりを実現 */
.avatar + .avatar {
  /* margin-left: -12px → 左のアバターに12px食い込ませる */
  margin-left: -12px;
}

/* z-indexで重なりの順序を制御 → 左が手前に来る */
.avatar:nth-child(1) { z-index: 5; background-color: #6366f1; }
.avatar:nth-child(2) { z-index: 4; background-color: #8b5cf6; }
.avatar:nth-child(3) { z-index: 3; background-color: #a855f7; }
.avatar:nth-child(4) { z-index: 2; background-color: #d946ef; }
.avatar:nth-child(5) { z-index: 1; background-color: #ec4899; }

/* ホバー時 → 拡大＆浮き上がり。z-index:10で最前面に */
.avatar:hover {
  transform: translateY(-4px) scale(1.1);
  z-index: 10;
}

/* スタック全体ホバー時 → 重なりを緩めて全員を見やすくする */
.avatar-stack:hover .avatar + .avatar {
  margin-left: -4px;
}

/* +N カウンター → グレー背景で「もっとある」を示す */
.avatar--counter {
  background-color: var(--color-bg-tertiary);
  color: var(--color-text-secondary);
  z-index: 0;
}

/* ツールチップ → data-tooltip属性の値を::afterで表示 */
.avatar[data-tooltip]::after {
  content: attr(data-tooltip);
  position: absolute;
  bottom: calc(100% + 8px);
  left: 50%;
  transform: translateX(-50%);
  opacity: 0;
  transition: opacity 150ms;
}

.avatar[data-tooltip]:hover::after {
  opacity: 1;
}
