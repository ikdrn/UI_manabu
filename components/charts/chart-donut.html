ドーナツチャート

conic-gradient()を使ったCSSのみのドーナツチャート。4つのセグメント、中心テキスト、凡例を備え、データの構成比を視覚的に表現します。

プレビュー

1,248
総タスク数
  • 完了済み 35%
  • 進行中 25%
  • レビュー待ち 22%
  • 未着手 18%

設計の意図

conic-gradient()による円グラフの実現
conic-gradient()は中心から放射状に色を変化させるグラデーション関数です。角度ではなくパーセンテージで指定でき、各セグメントの開始と終了を直感的に制御できます。

CSS変数でセグメントを管理する理由
セグメントの割合をCSS変数（カスタムプロパティ）で定義することで、JavaScriptからstyle.setProperty()で動的に値を変更できます。データの更新が容易で保守性が高い実装です。

::afterでドーナツの穴を作る
円グラフ（パイチャート）の中央に白い円を重ねることで「ドーナツ」形状にします。中央の空間には合計値やラベルを配置でき、情報密度を高められます。

コード解説

<div class="donut-chart-wrapper">

  <!-- ドーナツチャート本体 → conic-gradientで描画 -->
  <div class="donut-chart">
    <!-- 中心テキスト → z-indexでドーナツ穴の上に表示 -->
    <div class="donut-center">
      <div class="donut-center-value">1,248</div>
      <div class="donut-center-label">総タスク数</div>
    </div>
  </div>

  <!-- 凡例 → チャートの各セグメントの説明 -->
  <ul class="donut-legend">
    <li class="donut-legend-item">
      <span class="donut-legend-dot" style="background: #6366f1;"></span>
      <span>完了済み</span>
      <span class="donut-legend-value">35%</span>
    </li>
    <!-- 他のセグメントも同じ構造 -->
  </ul>

</div>
/* ドーナツチャート → conic-gradientで各セグメントを描画 */
.donut-chart {
  /* CSS変数でセグメントの割合を定義 → 保守性が高い */
  --segment-1: 35%;
  --segment-2: 25%;
  --segment-3: 22%;
  --segment-4: 18%;
  --color-1: #6366f1;
  --color-2: #8b5cf6;
  --color-3: #a855f7;
  --color-4: #d946ef;

  width: 200px;
  height: 200px;
  border-radius: 50%; /* 正方形を円に変換 */
  position: relative;

  /* conic-gradient() → 中心から放射状に色が変化するグラデーション
     各色の開始%と終了%を指定してセグメントを作る */
  background: conic-gradient(
    var(--color-1) 0% var(--segment-1),
    var(--color-2) var(--segment-1)
      calc(var(--segment-1) + var(--segment-2)),
    var(--color-3) calc(var(--segment-1) + var(--segment-2))
      calc(var(--segment-1) + var(--segment-2) + var(--segment-3)),
    var(--color-4) calc(var(--segment-1) + var(--segment-2) + var(--segment-3))
      100%
  );
}

/* ::after → 白い円を重ねてドーナツの穴を作る */
.donut-chart::after {
  content: '';
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  /* 60%のサイズ → 外側の40%がドーナツ部分になる */
  width: 60%;
  height: 60%;
  border-radius: 50%;
  background: var(--color-bg-primary); /* 背景色と同じ色 */
}

/* 中心テキスト → ドーナツ穴の中に表示 */
.donut-center {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  text-align: center;
  /* z-index: 1 → ::afterの上に表示する */
  z-index: 1;
}

/* 凡例のドット → チャートの色と一致させる */
.donut-legend-dot {
  width: 12px;
  height: 12px;
  border-radius: var(--radius-sm);
}
