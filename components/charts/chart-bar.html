棒グラフ

CSSのみで実装する棒グラフ。月ごとのデータを6本のバーで表示し、成長アニメーションとホバーツールチップを備えています。

プレビュー

1月
2月
3月
4月
5月
6月

設計の意図

flex-end配置でバーを下から積み上げる
align-items: flex-endを使うことで、各バーがコンテナの底辺から上に伸びる自然な棒グラフのレイアウトを実現します。heightのパーセンテージでデータ量を視覚的に表現します。

@keyframes growUpによる成長アニメーション
ページ読み込み時にバーが下から上に伸びるアニメーションを適用します。animation-delayをバーごとにずらすことで、左から右に順番に伸びる視覚効果を生み出します。

data-value属性とCSS ::afterによるツールチップ
HTML5のdata属性にデータ値を格納し、CSSのattr()関数で::after疑似要素のcontentとして表示します。JavaScriptなしでホバーツールチップを実装できます。

コード解説

<!-- 棒グラフのコンテナ → flex-endで底辺揃え -->
<div class="bar-chart">

  <!-- 各バーのアイテム -->
  <div class="bar-item">
    <!-- height → データ値をパーセントで表現 -->
    <!-- data-value → ツールチップに表示する値 -->
    <div class="bar"
         style="height: 65%;"
         data-value="65"></div>
    <span class="bar-label">1月</span>
  </div>

  <div class="bar-item">
    <div class="bar"
         style="height: 42%;"
         data-value="42"></div>
    <span class="bar-label">2月</span>
  </div>

  <!-- 他の月も同じ構造で繰り返す -->
</div>
/* グラフコンテナ → flexboxで底辺揃え */
.bar-chart {
  display: flex;
  /* align-items: flex-end → 子要素を下端に揃える
     これにより各バーが底辺から上に伸びる */
  align-items: flex-end;
  gap: var(--space-3);
  height: 240px;
  /* 左辺と下辺に軸線を表示 */
  border-bottom: 2px solid var(--color-border-secondary);
  border-left: 2px solid var(--color-border-secondary);
}

/* バー本体 */
.bar {
  width: 100%;
  max-width: 48px;
  /* 上だけ角丸 → バーの頂点を丸くする */
  border-radius: var(--radius-sm) var(--radius-sm) 0 0;
  /* グラデーションで立体感を出す */
  background: linear-gradient(180deg,
    var(--color-brand-400),
    var(--color-brand-600));

  /* growUpアニメーション → 下から上に成長 */
  animation: growUp 800ms ease-out forwards;
  /* transform-origin: bottom → 変形の基準点を下端に */
  transform-origin: bottom;
}

/* 各バーにアニメーション遅延を設定 → 順番に伸びる効果 */
.bar-item:nth-child(1) .bar { animation-delay: 0ms; }
.bar-item:nth-child(2) .bar { animation-delay: 100ms; }
.bar-item:nth-child(3) .bar { animation-delay: 200ms; }
/* ... */

/* @keyframes → バーの成長アニメーション定義 */
@keyframes growUp {
  from {
    /* scaleY(0) → 高さ0の状態からスタート */
    transform: scaleY(0);
    opacity: 0;
  }
  to {
    transform: scaleY(1);
    opacity: 1;
  }
}

/* ツールチップ → data-value属性の値を::afterで表示 */
.bar::after {
  /* attr(data-value) → HTML属性の値をCSS内で参照 */
  content: attr(data-value) '件';
  position: absolute;
  bottom: calc(100% + 8px);
  left: 50%;
  transform: translateX(-50%);
  opacity: 0; /* 通常時は非表示 */
  transition: opacity 150ms;
}

.bar:hover::after {
  opacity: 1; /* ホバー時に表示 */
}
