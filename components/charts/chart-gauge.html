ゲージメーター

半円形のゲージメーター。色分けされたゾーン（緑・黄・赤）と針のアニメーションで、現在の値を視覚的に表示します。パフォーマンス指標やスコア表示に最適です。

設計の意図

conic-gradientで色ゾーンを表現
conic-gradientで180度（半円分）に3つの色ゾーンを配置します。緑（良好）→黄（注意）→赤（危険）の直感的な色分けで、数値を読まなくても状態を瞬時に把握できます。

transform: rotateによる針のアニメーション
CSS変数--gauge-valueに応じてrotateの角度を計算します。0%が-90度（左端）、100%が90度（右端）に対応し、calc()で動的に角度を算出します。

cubic-bezierでバネのような動き
transition-timing-functionにcubic-bezier(0.34, 1.56, 0.64, 1)を指定することで、針が目標値を少し通り過ぎてから戻る「オーバーシュート」効果を実現します。

コード解説

<!-- ゲージコンテナ → --gauge-valueで値を設定 -->
<div class="gauge" style="--gauge-value: 72;">

  <!-- 色ゾーンの背景（半円） -->
  <div class="gauge-bg"></div>

  <!-- 下半分を隠すマスク -->
  <div class="gauge-mask"></div>

  <!-- ニードル（針）→ CSS変数に応じて回転 -->
  <div class="gauge-needle"></div>

  <!-- 値の表示 -->
  <div class="gauge-value">
    <span class="gauge-value-number">72</span>
    <span class="gauge-value-unit">%</span>
  </div>

  <!-- 目盛りラベル -->
  <div class="gauge-labels">
    <span>0</span>
    <span>100</span>
  </div>
</div>
/* ゲージコンテナ → overflow:hiddenで下半分を切り取る */
.gauge {
  --gauge-value: 72; /* CSS変数 → JSから変更可能 */
  width: 240px;
  height: 130px; /* 半円分の高さ */
  position: relative;
  overflow: hidden; /* 下半分を隠す */
}

/* 色ゾーンの背景 → conic-gradientで3色の半円 */
.gauge-bg {
  width: 240px;
  height: 240px;
  border-radius: 50%;

  /* conic-gradient(from 180deg, ...) → 180度（下）から開始
     0-60deg: 緑(良好), 60-120deg: 黄(注意), 120-180deg: 赤(危険)
     180-360deg: transparent（下半分は非表示） */
  background: conic-gradient(
    from 180deg,
    #22c55e 0deg 60deg,
    #eab308 60deg 120deg,
    #ef4444 120deg 180deg,
    transparent 180deg 360deg
  );
}

/* 内側の白い円 → ドーナツ状に見せるマスク */
.gauge-bg::after {
  content: '';
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  width: 70%; /* 外径の70% → 残り30%がゲージ部分 */
  height: 70%;
  border-radius: 50%;
  background: var(--color-bg-primary);
}

/* ニードル（針） → CSS変数で回転角度を制御 */
.gauge-needle {
  position: absolute;
  bottom: 0;
  left: 50%;
  width: 3px;
  height: 95px;
  background: var(--color-text-primary);

  /* transform-origin: bottom center → 底辺中央を回転軸にする */
  transform-origin: bottom center;

  /* calc(-90deg + ...) → 0%が左端(-90度)、100%が右端(90度)
     1.8deg = 180度/100 → 1%あたり1.8度 */
  transform: translateX(-50%)
    rotate(calc(-90deg + (var(--gauge-value) * 1.8deg)));

  /* cubic-bezier → オーバーシュートするバネのような動き */
  transition: transform 1.5s cubic-bezier(0.34, 1.56, 0.64, 1);
}
