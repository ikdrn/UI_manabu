チャート・データ可視化

折れ線グラフ

SVGで描画する折れ線グラフ。12個のデータポイント、グリッド線、線の描画アニメーション、グラデーション面積塗りつぶしを備えた本格的なチャートです。

プレビュー

設計の意図

SVG viewBoxによるレスポンシブ対応
viewBox="0 0 560 280"でSVGの仮想座標系を定義します。実際の表示サイズはCSSのwidth: 100%に従い、viewBoxの比率を保ったままスケーリングされます。

stroke-dasharrayによる描画アニメーション
stroke-dasharrayで線の見える部分と見えない部分のパターンを定義し、stroke-dashoffsetで開始位置をずらします。オフセットを0にアニメーションすることで「線が描かれていく」効果を生み出します。

linearGradientによる面積塗りつぶし
SVGのlinearGradient要素で上から下に透明度が変化するグラデーションを定義します。折れ線の下を塗りつぶすことで、データの推移をより直感的に把握できます。

コード解説

<!-- SVG要素 → viewBoxで仮想座標系を定義 -->
<svg class="line-chart-svg"
     viewBox="0 0 560 280"
     preserveAspectRatio="xMidYMid meet">

  <!-- defs → 再利用可能な定義を格納する領域 -->
  <defs>
    <!-- linearGradient → 面積塗りつぶし用のグラデーション -->
    <linearGradient id="areaGradient" x1="0" y1="0" x2="0" y2="1">
      <stop offset="0%" stop-color="#6366f1" stop-opacity="0.3"/>
      <stop offset="100%" stop-color="#6366f1" stop-opacity="0.02"/>
    </linearGradient>
  </defs>

  <!-- グリッドライン → 目盛りの基準線 -->
  <line class="grid-line" x1="50" y1="40" x2="540" y2="40"/>

  <!-- polygon → 面積塗りつぶし（線の下を塗る） -->
  <polygon class="chart-area"
    points="70,180 113,160 ... 540,240 70,240"
    fill="url(#areaGradient)"/>

  <!-- polyline → 折れ線。pointsに座標を列挙 -->
  <polyline class="chart-line"
    points="70,180 113,160 157,120 ..."/>

  <!-- circle → 各データポイント -->
  <circle class="data-point" cx="70" cy="180" r="4"
          data-label="1月: 30"/>
</svg>
/* 折れ線 → stroke-dasharrayで描画アニメーション */
.chart-line {
  fill: none; /* 内部は塗らない（線だけ） */
  stroke: var(--color-brand-500);
  stroke-width: 2.5;

  /* stroke-linecap: round → 線の端を丸くする */
  stroke-linecap: round;

  /* stroke-linejoin: round → 折れ点を丸くする */
  stroke-linejoin: round;

  /* stroke-dasharray → 線の可視部分のパターン
     1500は線全体の長さ以上の値 */
  stroke-dasharray: 1500;

  /* stroke-dashoffset → 描画開始位置をずらす
     1500（全長分）ずらすことで最初は何も見えない */
  stroke-dashoffset: 1500;

  /* animation → オフセットを0に戻して描画する */
  animation: drawLine 2s ease-out forwards;
}

@keyframes drawLine {
  to {
    /* stroke-dashoffset: 0 → 線が完全に表示される */
    stroke-dashoffset: 0;
  }
}

/* データポイント → ホバーで拡大 */
.data-point {
  fill: var(--color-bg-primary); /* 白い中心 */
  stroke: var(--color-brand-500); /* ブランドカラーの枠 */
  stroke-width: 2;
  cursor: pointer;
  /* r → SVGのcircle半径。CSSから変更可能 */
  transition: r 150ms;
}

.data-point:hover {
  r: 6; /* ホバー時に半径を大きくする */
  fill: var(--color-brand-500); /* 塗りつぶしに変更 */
}
// データポイントにホバーツールチップを追加
const tooltip = document.getElementById('chartTooltip');
const points = document.querySelectorAll('.data-point');

points.forEach(point => {
  // mouseenter → マウスがポイントに乗った時
  point.addEventListener('mouseenter', (e) => {
    // data-label属性からラベルテキストを取得
    tooltip.textContent = point.dataset.label;
    tooltip.classList.add('visible');
  });

  // mousemove → マウス移動に合わせてツールチップを追従
  point.addEventListener('mousemove', (e) => {
    tooltip.style.left = e.pageX + 12 + 'px';
    tooltip.style.top = e.pageY - 30 + 'px';
  });

  // mouseleave → マウスがポイントから離れた時
  point.addEventListener('mouseleave', () => {
    tooltip.classList.remove('visible');
  });
});
