日付ピッカー

カレンダー形式の日付ピッカーは、ユーザーが視覚的に日付を選択できるコンポーネントです。CSS Gridによるカレンダーレイアウト、JavaScriptのDate APIによる月の計算、今日の強調表示を実装します。

プレビュー：インラインカレンダー

設計の意図

CSS Gridで7列のカレンダーレイアウトを作る
grid-template-columns: repeat(7, 1fr)で曜日に対応した7列グリッドを作ります。日付ボタンを順番に並べるだけで、自動的にカレンダーの形になります。前月の末日で開始位置を調整するのがポイントです。

JavaScriptのDate APIでカレンダーを計算する
new Date(year, month, 0).getDate()でその月の日数を取得し、new Date(year, month, 1).getDay()で月初の曜日を知ります。この2つの情報があればカレンダーグリッドを構築できます。

今日の日付をハイライトする理由
ユーザーがカレンダーを見た瞬間に「今日」がわかることで、「3日後」「来週の水曜日」といった相対的な日付選択が容易になります。小さなドット（::after擬似要素）で控えめに示します。

日曜・土曜の色分け
日本のカレンダー慣習に合わせて、日曜を赤系、土曜を青系で表示します。休日の判定はロケールやAPIによって異なるため、ここでは曜日ベースの色分けのみ実装しています。

// --- カレンダー描画関数 ---
function renderCalendar(container, year, month, selectedDate) {
  const grid = container.querySelector('.calendar-grid');
  const title = container.querySelector('.calendar-title');

  // タイトルを「2026年3月」の形式で表示
  title.textContent = `${year}年${month + 1}月`;

  // --- 月の日数と開始曜日を計算 ---
  // new Date(year, month + 1, 0) → 翌月の0日目＝当月の最終日
  const daysInMonth = new Date(year, month + 1, 0).getDate();
  // new Date(year, month, 1).getDay() → 月初の曜日（0=日曜）
  const startDay = new Date(year, month, 1).getDay();
  // 前月の日数（カレンダーの先頭を埋めるため）
  const prevDays = new Date(year, month, 0).getDate();

  const today = new Date();
  grid.innerHTML = '';

  // --- 前月の日（グレー表示） ---
  for (let i = startDay - 1; i >= 0; i--) {
    const day = prevDays - i;
    const btn = createDayButton(day, 'outside');
    grid.appendChild(btn);
  }

  // --- 当月の日 ---
  for (let d = 1; d <= daysInMonth; d++) {
    const date = new Date(year, month, d);
    const dayOfWeek = date.getDay();
    const classes = [];

    // 今日かどうか判定
    if (date.toDateString() === today.toDateString()) {
      classes.push('today');
    }

    // 選択済みかどうか判定
    if (selectedDate &&
        date.toDateString() === selectedDate.toDateString()) {
      classes.push('selected');
    }

    // 曜日の色分け（日曜=0, 土曜=6）
    if (dayOfWeek === 0) classes.push('sun');
    if (dayOfWeek === 6) classes.push('sat');

    const btn = createDayButton(d, classes.join(' '));
    // aria-label → 「2026年3月22日」のような読み上げテキスト
    btn.setAttribute('aria-label',
      `${year}年${month + 1}月${d}日` +
      (classes.includes('today') ? '（今日）' : '')
    );
    grid.appendChild(btn);
  }

  // --- 翌月の日（残りのセルを埋める） ---
  const totalCells = grid.children.length;
  const remaining = (7 - totalCells % 7) % 7;
  for (let i = 1; i <= remaining; i++) {
    const btn = createDayButton(i, 'outside');
    grid.appendChild(btn);
  }
}

function createDayButton(day, classStr) {
  const btn = document.createElement('button');
  btn.type = 'button';
  btn.className = 'calendar-day';
  // クラス名を追加（today, selected, outside, sun, sat）
  if (classStr) {
    classStr.split(' ').forEach(c => {
      if (c) btn.classList.add('calendar-day--' + c);
    });
  }
  btn.textContent = day;
  return btn;
}

// --- 前月・次月ナビゲーション ---
let currentYear = new Date().getFullYear();
let currentMonth = new Date().getMonth();

document.querySelectorAll('.calendar-nav-btn').forEach(btn => {
  btn.addEventListener('click', () => {
    if (btn.dataset.dir === 'prev') {
      currentMonth--;

        currentMonth = 11;
        currentYear--;

      currentMonth++;
      if (currentMonth > 11) {
        currentMonth = 0;

      }

実運用でのエッジケース

うるう年（2月29日）

new Date(year, 2, 0).getDate()は自動的にうるう年を考慮して28または29を返します。特別な処理は不要です。

年をまたぐナビゲーション（12月 → 1月）

月を++/--した後に0未満なら年を-1、11超なら年を+1する処理が必要です。

タイムゾーンの問題

new Date()はブラウザのローカルタイムゾーンを使います。UTC基準で日付を扱う場合はgetUTCDate()などのUTCメソッドを使う必要があります。

月の初日が日曜日の場合

getDay()が0を返すため、前月の日を表示しなくてよいケースです。ループの開始条件i = startDay - 1が-1になり、ループが実行されません。
