テキスト入力

テキスト入力はフォームの基本要素です。ラベル、プレースホルダー、ヘルパーテキスト、エラー状態など、ユーザーが迷わず入力できるための工夫を学びます。

設計の意図

なぜラベルは入力フィールドの上に置くのか？
ラベルが上にあると、視線が上→下と自然に流れます。左配置に比べてモバイルでも崩れにくく、入力フィールドとの関係が明確になります。

フローティングラベルの利点と注意点
スペース節約には有効ですが、縮小したラベルが小さすぎると読みにくくなります。:placeholder-shown擬似クラスを使い、入力がない時だけプレースホルダー位置にラベルを表示します。

エラーは「いつ」表示するか？
入力中にリアルタイムでエラーを出すと煩わしいため、フォーカスを外した時（blur）に検証するのが一般的です。aria-invalidとaria-describedbyでスクリーンリーダーにもエラーを伝えます。

文字数カウントで「あとどれだけ書けるか」を伝える
SNSの投稿や自己紹介欄など、制限があるフィールドでは残り文字数を見せることで、ユーザーが安心して入力を調整できます。

.form-input {
  /* padding → 上下10px、左右12pxの内側余白。
     十分なクリック領域を確保する */
  padding: 10px 12px;

  /* border → 1pxの実線ボーダー。入力欄の境界を明確にする */
  border: 1px solid var(--color-border-default);

  /* border-radius → 角丸で柔らかい印象にする */
  border-radius: var(--radius-md);

  /* outline: none → ブラウザデフォルトのフォーカス枠を消す。
     代わりに:focusで独自のスタイルを指定する */
  outline: none;

  /* transition → ボーダー色とシャドウの変化をなめらかにする */
  transition: border-color 150ms, box-shadow 150ms;
}

/* :focus → フォーカス時にブランドカラーのボーダーと
   薄い影で「ここに入力中」を視覚的に示す */
.form-input:focus {
  border-color: var(--color-brand-500);
  box-shadow: 0 0 0 3px hsla(222, 80%, 50%, 0.15);
}

/* エラー状態 → 赤いボーダーで即座に問題を伝える */
.form-input--error {
  border-color: #e53e3e;
}

/* --- フローティングラベルの仕組み --- */
.floating-label {
  /* position: absolute → 入力欄の上に重ねて配置する */
  position: absolute;
  left: 12px;
  top: 50%;
  transform: translateY(-50%);

  /* pointer-events: none → ラベルをクリックしても
     下のinputにフォーカスが届くようにする */
  pointer-events: none;

  /* transition → 移動アニメーション */
  transition: all 150ms;
}

/* :placeholder-shown → placeholderが見えている時（＝入力が空）。
   この擬似クラスの「否定（:not）」で入力がある時を検出する */
.floating-input:focus + .floating-label,
.floating-input:not(:placeholder-shown) + .floating-label {
  top: 10px;
  transform: translateY(0);
  font-size: 0.75rem;
  color: var(--color-brand-500);
}

/* :disabled → 無効状態。背景をグレーにし、操作不可を伝える */
.form-input:disabled {
  background-color: #f5f5f5;
  cursor: not-allowed;
  opacity: 0.6;
}
// --- 文字数カウント ---
// 入力イベントを監視して、現在の文字数を表示する

const bioInput = document.getElementById('bio');
const bioCount = document.getElementById('bio-count');
const maxLen = 50;

bioInput.addEventListener('input', () => {
  // value.length → 現在の入力文字数を取得
  const len = bioInput.value.length;
  bioCount.textContent = `${len} / ${maxLen}`;

  // 上限を超えたら警告色にする
  if (len >= maxLen) {
    bioCount.classList.add('char-count--over');
  } else {
    bioCount.classList.remove('char-count--over');
  }
});
