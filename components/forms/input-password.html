パスワード入力

パスワード入力は、セキュリティと使いやすさのバランスが求められるコンポーネントです。表示/非表示トグル、強度メーター、要件チェックリストを組み合わせて、ユーザーが安全なパスワードを設定できるよう導きます。

プレビュー

  • 8文字以上
  • 大文字を1つ以上含む
  • 小文字を1つ以上含む
  • 数字を1つ以上含む
  • 記号を1つ以上含む（@#$%など）

設計の意図

なぜ「表示/非表示」トグルが必要なのか？
パスワードが●●●●で隠されていると、タイプミスに気づけません。特にモバイルでは誤入力が多いため、表示トグルを用意するのが現代のベストプラクティスです。type="password"とtype="text"をJavaScriptで切り替えます。

強度メーターで「セキュリティの可視化」を実現する
「弱い」「普通」「強い」の3段階を色とバーの長さで表現します。CSSのtransition: widthでバーがなめらかに伸びるアニメーションを作り、ユーザーに達成感を与えます。

要件チェックリストで「何が足りないか」を明示する
「パスワードが弱い」とだけ表示されても、ユーザーは何を直せばよいかわかりません。各要件を個別にチェックし、満たされたものにはチェックマークを表示することで、具体的なガイダンスを提供します。

正規表現（regex）でのバリデーション
/[A-Z]/（大文字）、/[0-9]/（数字）などの正規表現で各要件をテストします。正規表現はフォームバリデーションの基本スキルです。

// --- 表示/非表示トグル ---
const input = document.getElementById('password-demo');
const toggle = document.querySelector('.password-toggle');
const iconShow = toggle.querySelector('.icon-show');
const iconHide = toggle.querySelector('.icon-hide');

toggle.addEventListener('click', () => {
  // type属性を切り替える
  const isPassword = input.type === 'password';
  input.type = isPassword ? 'text' : 'password';

  // アイコンを切り替える
  iconShow.style.display = isPassword ? 'none' : 'block';
  iconHide.style.display = isPassword ? 'block' : 'none';

  // aria-labelを更新（スクリーンリーダー向け）
  toggle.setAttribute('aria-label',
    isPassword ? 'パスワードを隠す' : 'パスワードを表示'
  );
});

// --- 要件チェック（正規表現バリデーション） ---
const requirements = {
  length:    (v) => v.length >= 8,        // 8文字以上
  uppercase: (v) => /[A-Z]/.test(v),       // 大文字1つ以上
  lowercase: (v) => /[a-z]/.test(v),       // 小文字1つ以上
  number:    (v) => /[0-9]/.test(v),       // 数字1つ以上
  special:   (v) => /[^A-Za-z0-9]/.test(v) // 記号1つ以上
};

// --- 強度計算 ---
const labels = ['', '弱い', '普通', '強い'];

input.addEventListener('input', () => {
  const val = input.value;
  let metCount = 0;

  // 各要件をチェックしてDOMを更新
  Object.entries(requirements).forEach(([key, test]) => {
    const el = document.querySelector(`[data-req="${key}"]`);
    const passed = test(val);
    el.classList.toggle('met', passed);
    if (passed) metCount++;
  });

  // 5つの要件のうち何個満たしたかで強度を決める
  let level = 0;
  if (val.length > 0) {
    if (metCount <= 2) level = 1;       // 弱い
    else if (metCount <= 4) level = 2;  // 普通
    else level = 3;                       // 強い
  }

  // 強度バーとラベルを更新
  const fill = document.getElementById('strength-fill');
  const label = document.getElementById('strength-text');
  fill.setAttribute('data-level', level);
  label.setAttribute('data-level', level);
  label.textContent = labels[level];
});

コピー&ペーストされたパスワード

inputイベントはペーストでも発火するため、強度チェックは正しく動作します。pasteイベントを別途監視する必要はありません。

パスワードマネージャーとの競合

autocomplete="new-password"を指定すると、ブラウザのパスワードマネージャーが「新しいパスワードの保存」ダイアログを適切に表示します。
