設計の意図

なぜアクセシビリティは「あると良い」ではなく「必須」なのか
日本では障害者差別解消法により、Webサイトのアクセシビリティ対応は努力義務です。また、全人口の約15%が何らかの障害を持つとされ、一時的な障害（骨折、目の手術後）を含めるとさらに多くの人が恩恵を受けます。

role="switch" の意味
スクリーンリーダーはこの要素を「スイッチ」として読み上げ、「オン」「オフ」の状態を伝えます。role="checkbox"とは異なり、即座に効果が反映されることを暗示します。

色だけに頼らない状態表示
色覚特性のあるユーザーのために、ON/OFFは色だけでなく位置（左/右）とテキスト（ON/OFF）でも示します。

prefers-reduced-motion
前庭障害や視覚過敏のあるユーザーは、アニメーションで体調を崩すことがあります。このメディアクエリでアニメーションを無効化できます。

/* :focus-visible → キーボード操作時のみフォーカスリングを表示。
   マウスクリック時には出ない（:focusだと両方で出る） */
.toggle-switch:focus-visible {
  outline: 3px solid var(--color-brand-400);
  outline-offset: 2px; /* スイッチから少し離して見やすくする */
}

/* prefers-reduced-motion: reduce → ユーザーがOS設定で
   「動きを減らす」を選んでいる場合、アニメーションを無効化 */
@media (prefers-reduced-motion: reduce) {
  .toggle-switch,
  .toggle-switch::before {
    transition: none; /* すべてのアニメーションを即座に切り替え */
  }
}

/* forced-colors: active → Windows高コントラストモード対応。
   通常のCSSカラーが上書きされるため、システムカラーを使う */
@media (forced-colors: active) {
  .toggle-switch {
    border: 2px solid ButtonText; /* システムのボタンテキスト色 */
  }
  .toggle-switch[aria-checked="true"] {
    background: Highlight; /* システムのハイライト色 */
  }
}
/* すべてのトグルスイッチに対してイベントを設定 */
document.querySelectorAll('.toggle-switch').forEach(function(toggle) {

  /* toggle関数 → 状態を反転させる */
  function toggleSwitch() {
    /* aria-checkedの値を取得して反転 */
    var isChecked = toggle.getAttribute('aria-checked') === 'true';
    var newState = !isChecked;

    /* aria-checkedを更新 → スクリーンリーダーが状態変化を通知 */
    toggle.setAttribute('aria-checked', String(newState));

    /* 表示テキストも更新（色に頼らない状態表示） */
    var status = toggle.querySelector('.toggle-status');
    if (status) {
      status.textContent = newState ? 'ON' : 'OFF';
    }
  }

  /* クリックで切り替え */
  toggle.addEventListener('click', toggleSwitch);

  /* キーボード操作: SpaceキーまたはEnterキーで切り替え */
  toggle.addEventListener('keydown', function(e) {
    if (e.key === ' ' || e.key === 'Enter') {
      /* preventDefault → Spaceキーのスクロール、Enterのフォーム送信を防ぐ */
      e.preventDefault();
      toggleSwitch();
    }
  });
});
