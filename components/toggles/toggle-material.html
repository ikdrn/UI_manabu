設計の意図

サムがトラックより大きい理由
マテリアルデザインでは、サム（つまみ）がトラックから少しはみ出します。これはタップ可能な領域を視覚的に示し、物理的なスイッチの「つまむ」感覚を再現しています。

リップルエフェクト（波紋）
ホバーやタップ時に淡い円形が広がるエフェクトは、ユーザーの操作に対するフィードバックです。「ここに触れている」ことを視覚的に確認できます。

44pxタッチターゲット
サムの周囲にリップル領域を設けることで、見た目は24pxでも実際のタッチ可能領域は40px以上を確保しています。

コード解説

.toggle-material {
  /* CSS変数でサイズを一箇所管理 → 後からサイズ変更が簡単 */
  --toggle-width: 52px;
  --thumb-size: 24px;
  /* position: relative → サム（丸）をabsoluteで配置するための基準点 */
  position: relative;
  cursor: pointer;
}

/* チェックボックスを見えなくする（機能は残す） */
.toggle-material input {
  position: absolute;
  opacity: 0; /* 透明にするだけ → フォーカスやクリックは受け取れる */
}

/* トラック（レール部分） */
.toggle-track {
  width: var(--toggle-width);
  height: 32px;
  background: var(--color-neutral-300);
  /* border-radius: 9999px → 高さに関係なく完全な丸端になる */
  border-radius: 9999px;
  transition: background 250ms;
}

/* サム（つまみ） — position: absoluteでトラックの上に浮かせる */
.toggle-thumb {
  position: absolute;
  top: 50%;
  left: 4px;
  width: var(--thumb-size);
  height: var(--thumb-size);
  background: white;
  border-radius: 50%;
  /* translateY(-50%) → 縦方向の中央揃え */
  transform: translateY(-50%);
  transition: left 250ms cubic-bezier(0.16, 1, 0.3, 1);
  box-shadow: 0 1px 3px hsla(0,0%,0%,0.2);
}

/* リップル（波紋）エフェクト — ::afterで見えない大きな円を作る */
.toggle-thumb::after {
  content: "";
  position: absolute;
  /* inset: -8px → 上下左右に8px拡張した領域 */
  inset: -8px;
  border-radius: 50%;
  background: transparent;
}
.toggle-material:hover .toggle-thumb::after {
  /* ホバーで薄い色の円を表示 → リップルの第1段階 */
  background: hsla(222, 80%, 50%, 0.08);
}

/* チェック時 → サムを右に移動、色を変える */
input:checked + .toggle-track .toggle-thumb {
  /* calc()で右端の位置を計算 */
  left: calc(var(--toggle-width) - var(--thumb-size) - 4px);
  background: var(--color-brand-500);
}
