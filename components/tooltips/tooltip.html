ツールチップ

ツールチップ

要素にマウスを乗せた時やキーボードフォーカス時に、補足情報を小さな吹き出しで表示するUIパターン。CSSの疑似要素（::before / ::after）だけで実装でき、JavaScriptは不要です。

プレビュー

複数行ツールチップ

アイコンボタンとの組み合わせ

設計の意図

ツールチップは補足情報のみに使う
ツールチップは「あると便利だが、なくても操作できる」情報に限定します。必須の情報をツールチップに隠すと、モバイルユーザーはアクセスできません（タッチデバイスにはhoverがない）。

表示までの遅延（delay）を設ける理由
マウスが一瞬通過しただけでツールチップが出ると、画面がちらついて邪魔になります。150ms程度の遅延を入れることで、意図的にホバーした時だけ表示されるようになり、UXが向上します。

テキストは短く保つ
ツールチップは数語〜1文程度に収めます。長い説明が必要な場合は、ツールチップではなくポップオーバーやヘルプテキストを検討してください。

タッチデバイスでの制約
スマートフォンやタブレットではhoverイベントが存在しないため、CSSのみのツールチップは機能しません。モバイル対応が必要な場合は、タップで表示/非表示を切り替えるJavaScript実装や、最初から情報を表示しておくアプローチを検討します。

/* === ツールチップのトリガー（親要素） === */
.tooltip-trigger {
  /* position: relative → 子要素（ツールチップ）のposition: absoluteの
     基準点になる。これがないとツールチップが画面の端に飛んでいく */
  position: relative;
}

/* === ツールチップ本体（::after疑似要素） === */
.tooltip-trigger::after {
  /* content: attr(data-tooltip) →
     HTMLのdata-tooltip属性の値をそのまま表示する。
     例：data-tooltip="保存しました" → "保存しました" と表示される。
     JavaScriptを使わずにCSSだけでテキスト内容を動的に設定できる */
  content: attr(data-tooltip);

  /* position: absolute → 通常のレイアウトから切り離し、
     親要素（relative）を基準に自由に配置できるようにする */
  position: absolute;

  padding: 6px 12px;
  font-size: 12px;
  color: white;
  background-color: #1e293b;
  border-radius: 4px;

  /* white-space: nowrap → テキストを1行に保つ。
     短いツールチップでは改行させない方が読みやすい */
  white-space: nowrap;

  /* pointer-events: none → ツールチップを「透明な壁」にする。
     これがないと問題が起きる：
     1. マウスがボタンからツールチップ上に移動
     2. ボタンから離れたのでツールチップが消える
     3. ボタンが見えるので再びホバー
     4. ツールチップが出る → 1に戻る（ちらつきの無限ループ） */
  pointer-events: none;

  /* --- 非表示状態 ---
     なぜ display: none を使わないのか？
     → display プロパティは transition（アニメーション）が効かない。
       display: none → display: block に変わると、瞬時に表示されてしまう。
     → visibility + opacity なら transition で滑らかに変化させられる。
       visibility: hidden → visible は「存在するが見えない→見える」
       opacity: 0 → 1 は「透明→不透明」のフェード効果 */
  visibility: hidden;
  opacity: 0;

  /* transition の第2引数（150ms）は遅延時間。
     マウスが一瞬通り過ぎただけでは表示しない＝誤表示防止 */
  transition: visibility 200ms 150ms,
              opacity 200ms 150ms;
}

/* === 矢印（::before疑似要素） === */
.tooltip-trigger::before {
  content: "";
  position: absolute;

  /* --- CSSで三角形を作る「border trick」の仕組み ---
     width: 0; height: 0 の要素にborderを付けると：
     ┌───────┐
     │＼   ／│  ← 4つの三角形が集まった形になる
     │  ＼／  │
     │  ／＼  │
     │／   ＼│
     └───────┘
     全てのborderをtransparent（透明）にして、
     1辺だけ色を付ければ三角形が見える。

     例：上向き矢印 = border-bottomだけ色付き
     　　下向き矢印 = border-topだけ色付き */
  border: 6px solid transparent;

  pointer-events: none;
  visibility: hidden;
  opacity: 0;
  transition: visibility 200ms 150ms,
              opacity 200ms 150ms;
}

/* === ホバー/フォーカス時に表示 === */
.tooltip-trigger:hover::after,
.tooltip-trigger:hover::before,
.tooltip-trigger:focus-visible::after,
.tooltip-trigger:focus-visible::before {
  visibility: visible;
  opacity: 1;
}

/* === 上方向の配置 === */
.tooltip-top::after {
  /* bottom: 100% → 親要素の上端から、さらに上に配置。
     「100%」は親要素の高さ分 */
  bottom: 100%;

  /* left: 50% + translateX(-50%) → 水平中央揃え。
     left: 50% → 左端を親の中央に
     translateX(-50%) → 自分の幅の50%だけ左にずらす
     → 結果として要素の中心が親の中心に一致する */
  left: 50%;
  transform: translateX(-50%);
  margin-bottom: 8px;
}

.tooltip-top::before {
  border-top-color: #1e293b; /* 上辺だけ色をつける → 下向き三角 */
  bottom: 100%;
  left: 50%;
  transform: translateX(-50%);
  margin-bottom: 2px;
}

/* === 右方向の配置 === */
.tooltip-right::after {
  left: 100%;  /* 親の右端の外側に配置 */
  top: 50%;
  transform: translateY(-50%); /* 垂直方向の中央揃え */
  margin-left: 8px;
}

.tooltip-right::before {
  border-right-color: #1e293b; /* 右辺だけ色 → 左向き三角（矢印は内側を指す） */
  left: 100%;
  top: 50%;
  transform: translateY(-50%);
  margin-left: 2px;
}

/* === 下方向の配置 === */
.tooltip-bottom::after {
  top: 100%;  /* 親の下端の外側に配置 */
  left: 50%;
  transform: translateX(-50%);
  margin-top: 8px;
}

.tooltip-bottom::before {
  border-bottom-color: #1e293b; /* 下辺だけ色 → 上向き三角 */
  top: 100%;
  left: 50%;
  transform: translateX(-50%);
  margin-top: 2px;
}

/* === 左方向の配置 === */
.tooltip-left::after {
  right: 100%;  /* 親の左端の外側に配置 */
  top: 50%;
  transform: translateY(-50%);
  margin-right: 8px;
}

.tooltip-left::before {
  border-left-color: #1e293b; /* 左辺だけ色 → 右向き三角 */
  right: 100%;
  top: 50%;
  transform: translateY(-50%);
  margin-right: 2px;
}

/* === 複数行ツールチップ === */
.tooltip-multiline::after {
  /* white-space: normal → nowrapを上書きして折り返しを許可 */
  white-space: normal;

  /* max-width → 無制限に横に広がるのを防ぐ。
     この値を超えるとテキストが自動で改行される */
  max-width: 240px;
  text-align: left;
}

実運用でのエッジケース

画面端での表示（はみ出しの可能性）

※ CSSのみの実装では画面端のはみ出し検知ができません。JavaScriptで要素の位置を計算し、方向を動的に切り替える必要があります。

長いツールチップテキスト
タッチデバイスでの挙動

スマートフォンやタブレットでは :hover が使えないため、CSSのみのツールチップは表示されません。モバイル対応が必要な場合は、以下の代替手段を検討してください：

  • JavaScriptでタップ表示/非表示を実装
  • ツールチップの内容をインラインテキストとして常時表示
  • title 属性を使う（ブラウザ標準のツールチップ、ただしスタイル変更不可）
