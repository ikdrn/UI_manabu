タブナビゲーション

同一画面内でコンテンツを切り替えるタブUI。WAI-ARIAのタブパターンに準拠し、キーボード操作にも完全対応します。

プレビュー

製品概要

このタブには製品の概要が表示されます。タブをクリックするか、キーボードの矢印キーで他のタブに移動できます。

設計の意図

WAI-ARIAタブパターン
role="tablist"、role="tab"、role="tabpanel" を使い、各要素の関係性をスクリーンリーダーに伝えます。aria-selected="true" で選択中のタブを示し、aria-controls でタブとパネルを紐付けます。

キーボードナビゲーション
←→矢印キーでタブ間を移動、Home/Endで最初/最後に移動します。tabindex を制御することで、Tab キーではタブリストに1回だけフォーカスし、その後パネルに移動する効率的な操作を実現します。

アニメーション付き下線インジケーター
選択中のタブの下に線を引くだけでなく、タブ切り替え時に線がスライドするアニメーションを付けることで、「どこから何処へ移動したか」を視覚的に伝えます。

コード解説

<div class="tabs">
  <!-- role="tablist" → この領域がタブのリストであることを示す -->
  <div class="tabs__list" role="tablist" aria-label="サンプルタブ">

    <!-- role="tab" → タブボタンであることを示す -->
    <!-- aria-selected → 選択中かどうか -->
    <!-- aria-controls → このタブが制御するパネルのID -->
    <!-- tabindex="0" → 選択中タブにフォーカス可能 -->
    <button class="tabs__tab" role="tab"
            aria-selected="true"
            aria-controls="panel-1"
            id="tab-1"
            tabindex="0">概要</button>

    <!-- tabindex="-1" → 非選択タブはTab順序から除外 -->
    <button class="tabs__tab" role="tab"
            aria-selected="false"
            aria-controls="panel-2"
            id="tab-2"
            tabindex="-1">仕様</button>

    <!-- インジケーター用のdiv（JSで位置を制御） -->
    <div class="tabs__indicator"></div>
  </div>

  <!-- role="tabpanel" → タブに対応するコンテンツ領域 -->
  <!-- aria-labelledby → 対応するタブのIDで紐付け -->
  <div class="tabs__panel is-active" role="tabpanel"
       id="panel-1" aria-labelledby="tab-1" tabindex="0">
    パネル1の内容...
  </div>
</div>
/* --- タブリスト --- */
.tabs__list {
  display: flex;
  position: relative; /* インジケーターの位置基準 */
  border-bottom: 2px solid var(--color-neutral-200);
}

/* --- アニメーション付きインジケーター --- */
.tabs__indicator {
  position: absolute;
  bottom: -2px;        /* ボーダーの上に重ねる */
  height: 2px;
  background: var(--color-brand-500);
  /* left と width を transition で滑らかに移動 */
  transition: left 250ms cubic-bezier(0.16, 1, 0.3, 1),
              width 250ms cubic-bezier(0.16, 1, 0.3, 1);
}

/* --- パネルのフェードインアニメーション --- */
@keyframes tab-fade-in {
  from { opacity: 0; transform: translateY(4px); }
  to   { opacity: 1; transform: translateY(0); }
}

.tabs__panel.is-active {
  display: block;
  animation: tab-fade-in 250ms ease-out;
}
function initTabs(container) {
  const tabs = container.querySelectorAll('[role="tab"]');
  const panels = container.querySelectorAll('[role="tabpanel"]');
  const indicator = container.querySelector('.tabs__indicator');

  // インジケーターの位置を更新する関数
  function moveIndicator(tab) {
    indicator.style.left = tab.offsetLeft + 'px';
    indicator.style.width = tab.offsetWidth + 'px';
  }

  // タブを選択する関数
  function selectTab(tab) {
    // 全タブを非選択にする
    tabs.forEach(t => {
      t.setAttribute('aria-selected', 'false');
      t.setAttribute('tabindex', '-1');
    });

    // 全パネルを非表示にする
    panels.forEach(p => p.classList.remove('is-active'));

    // 選択したタブをアクティブに
    tab.setAttribute('aria-selected', 'true');
    tab.setAttribute('tabindex', '0');
    tab.focus();

    // 対応するパネルを表示
    const panelId = tab.getAttribute('aria-controls');
    document.getElementById(panelId).classList.add('is-active');

    // インジケーターを移動
    moveIndicator(tab);
  }

  // クリックイベント
  tabs.forEach(tab => {
    tab.addEventListener('click', () => selectTab(tab));
  });

  // キーボードナビゲーション
  container.querySelector('[role="tablist"]')
    .addEventListener('keydown', (e) => {
      const current = [...tabs].findIndex(
        t => t.getAttribute('aria-selected') === 'true'
      );
      let next;

      switch (e.key) {
        case 'ArrowRight': next = (current + 1) % tabs.length; break;
        case 'ArrowLeft':  next = (current - 1 + tabs.length) % tabs.length; break;
        case 'Home':       next = 0; break;
        case 'End':        next = tabs.length - 1; break;
        default: return;
      }
      e.preventDefault();
      selectTab(tabs[next]);
    });

  // 初期表示時にインジケーター位置をセット
  const activeTab = container.querySelector('[aria-selected="true"]');
  if (activeTab) moveIndicator(activeTab);
}
