ナビゲーション

モバイルボトムナビ

モバイルアプリでよく使われる画面下部固定のナビゲーション。アイコンとラベルの4項目で、主要な画面に素早くアクセスできます。

プレビュー

画面コンテンツ領域
実運用では position: fixed で画面下部に固定
ホーム 検索 通知 マイページ

設計の意図

position: fixed + env(safe-area-inset-bottom)
固定配置で常に画面下部に表示します。iPhoneのホームインジケーター領域と重ならないように env(safe-area-inset-bottom) で下余白を確保します。

4〜5項目が最適
ボトムナビの項目数は3〜5が推奨されます。多すぎるとタップ領域が狭くなり操作しにくくなります。6項目以上ある場合は「その他」メニューにまとめます。

アイコン＋テキストラベル
アイコンだけでは意味が伝わらないことがあるため、必ずテキストラベルを添えます。アクティブ状態は色変更に加え、上部に小さなインジケーターバーを表示して視認性を高めます。

コード解説

<!-- nav要素で囲み、aria-labelで識別 -->
<nav class="bottom-nav bottom-nav--fixed"
     aria-label="メインナビゲーション">

  <!-- 各アイテム：a要素でリンク。is-activeで現在のページ -->
  <a href="/" class="bottom-nav__item is-active"
     aria-current="page">
    <!-- SVGアイコン：インラインで配置 -->
    <svg class="bottom-nav__icon" viewBox="0 0 24 24">
      <path d="M3 12l2-2m0 0l7-7 7 7..."></path>
    </svg>
    <!-- テキストラベル：アイコンの意味を補足 -->
    <span class="bottom-nav__label">ホーム</span>
  </a>

  <a href="/search" class="bottom-nav__item">
    <svg class="bottom-nav__icon" viewBox="0 0 24 24">...</svg>
    <span class="bottom-nav__label">検索</span>
  </a>
  <!-- ... 残りのアイテム -->
</nav>
.bottom-nav {
  /* flex で均等配置 */
  display: flex;
  justify-content: space-around;

  /* 画面下部に固定 */
  position: fixed;
  bottom: 0;
  left: 0;
  right: 0;

  background: var(--color-surface-raised);
  border-top: 1px solid var(--color-neutral-200);

  /* env(safe-area-inset-bottom) →
     iPhoneのホームインジケーター領域分の余白を確保。
     対応していないブラウザでは 0px がフォールバック */
  padding-bottom: env(safe-area-inset-bottom, 0px);

  z-index: var(--z-sticky);
}

.bottom-nav__item {
  /* 縦方向に積む：アイコン → ラベル */
  display: flex;
  flex-direction: column;
  align-items: center;
  gap: 2px;

  /* flex: 1 → 全アイテムが均等幅 */
  flex: 1;

  /* タップ対象は44px以上を推奨 */
  padding: 8px 4px;
  font-size: 10px;
  color: var(--color-neutral-400);

  /* iOS Safariのタップハイライトを消す */
  -webkit-tap-highlight-color: transparent;
}

/* アクティブ状態のインジケーターバー */
.bottom-nav__item.is-active::before {
  content: '';
  position: absolute;
  top: 0;
  left: 50%;
  transform: translateX(-50%);
  width: 24px;
  height: 2px;
  background: var(--color-brand-500);
}
