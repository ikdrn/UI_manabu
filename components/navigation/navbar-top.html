実運用では position: sticky でスクロール時も上部に固定されます

設計の意図

なぜ backdrop-filter: blur を使うのか？
半透明の背景にブラーを掛けることで、コンテンツの上に浮いている感覚を出しつつ、下のコンテンツが完全に隠れないため圧迫感が軽減されます。

position: sticky vs fixed
sticky はスクロール時に上部に固定されますが、通常のドキュメントフロー内に留まるため、下のコンテンツが自動的に押し下げられます。fixed は完全に浮くため、body に padding-top が必要になります。

モバイルでのハンバーガーメニュー
画面幅が狭い時、全リンクを横に並べると読めなくなります。ハンバーガーアイコンに格納することで、必要な時だけ展開できるようにします。CSSだけで3本線から×への変形アニメーションを実現しています。

コード解説

<!-- nav要素 → ナビゲーションのセマンティックタグ -->
<!-- aria-label → スクリーンリーダーに「これはメインナビ」と伝える -->
<nav class="navbar" aria-label="メインナビゲーション">

  <!-- ロゴ：トップページへのリンク -->
  <a href="/" class="navbar__logo">MyApp</a>

  <!-- ナビリンク群：ul/liで意味的にリスト化 -->
  <ul class="navbar__links">
    <li><a href="/" class="navbar__link navbar__link--active">ホーム</a></li>
    <li><a href="/features" class="navbar__link">機能</a></li>
    <li><a href="/pricing" class="navbar__link">料金</a></li>
    <li><a href="/contact" class="navbar__link">お問い合わせ</a></li>
  </ul>

  <!-- CTA：最も目立つアクションボタン -->
  <a href="/signup" class="navbar__cta">無料で始める</a>

  <!-- ハンバーガー：モバイル時のみ表示 -->
  <!-- aria-expanded → メニューの開閉状態をスクリーンリーダーに伝える -->
  <button class="navbar__hamburger"
          aria-expanded="false"
          aria-label="メニューを開く">
    <span></span><span></span><span></span>
  </button>

  <!-- モバイルメニュー：ハンバーガー押下で表示 -->
  <div class="navbar__mobile-menu">
    <a href="/" class="navbar__link">ホーム</a>
    <a href="/features" class="navbar__link">機能</a>
    <a href="/pricing" class="navbar__link">料金</a>
    <a href="/contact" class="navbar__link">お問い合わせ</a>
    <a href="/signup" class="navbar__cta">無料で始める</a>
  </div>
</nav>
/* --- ナビバー本体 --- */
.navbar {
  /* position: sticky → スクロールしても画面上部に固定される。
     fixedと違い、通常フロー内に留まるのでレイアウトが崩れにくい */
  position: sticky;
  top: 0;

  /* z-index → 他の要素より上に表示。変数で管理して衝突を防ぐ */
  z-index: var(--z-sticky);

  /* display: flex → 横並びにして、ロゴ・リンク・CTAを配置 */
  display: flex;
  align-items: center;
  justify-content: space-between;

  /* 半透明背景＋ブラー → すりガラス効果。
     下のコンテンツが透けて見えるがぼやけるので邪魔にならない */
  background: hsla(0, 0%, 100%, 0.85);
  backdrop-filter: blur(12px);
  -webkit-backdrop-filter: blur(12px); /* Safari対応 */

  border-bottom: 1px solid var(--color-neutral-200);
}

/* --- ハンバーガーメニューのCSS変形 --- */
.navbar__hamburger {
  /* デフォルトは非表示。モバイル時のみdisplay:flexに */
  display: none;
  flex-direction: column;
  gap: 5px;
}

/* span3本で三本線を描く。CSSだけでアイコンを作る手法 */
.navbar__hamburger span {
  display: block;
  height: 2px;
  background: var(--color-neutral-700);
  transition: transform 250ms, opacity 150ms;
}

/* ×アニメーション：上の線を回転、中央を消す、下の線を逆回転 */
.navbar__hamburger[aria-expanded="true"] span:nth-child(1) {
  transform: translateY(7px) rotate(45deg);
}
.navbar__hamburger[aria-expanded="true"] span:nth-child(2) {
  opacity: 0;
}
.navbar__hamburger[aria-expanded="true"] span:nth-child(3) {
  transform: translateY(-7px) rotate(-45deg);
}

/* --- レスポンシブ切り替え --- */
@media (max-width: 768px) {
  /* PCのリンク群とCTAを隠して、ハンバーガーを出す */
  .navbar__links { display: none; }
  .navbar__cta-desktop { display: none; }
  .navbar__hamburger { display: flex; }
}
// ハンバーガーメニューの開閉処理
const hamburger = document.querySelector('.navbar__hamburger');
const mobileMenu = document.querySelector('.navbar__mobile-menu');

hamburger.addEventListener('click', () => {
  // aria-expandedを切り替え → CSSが×アニメーションを制御
  const isOpen = hamburger.getAttribute('aria-expanded') === 'true';
  hamburger.setAttribute('aria-expanded', !isOpen);

  // メニューの表示/非表示をクラスで切り替え
  mobileMenu.classList.toggle('is-open');

  // aria-labelも状態に合わせて更新
  hamburger.setAttribute('aria-label',
    isOpen ? 'メニューを開く' : 'メニューを閉じる'
  );
});
