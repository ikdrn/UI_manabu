設計の意図

nav + ol でマークアップする理由
パンくずリストは順序のある階層構造なので、ol（順序付きリスト）が意味的に正しい選択です。nav要素で囲み aria-label を付けることで、スクリーンリーダーユーザーがページ内のナビゲーション領域を識別できます。

現在のページはリンクにしない
最後の項目（現在のページ）は span にして aria-current="page" を付けます。自分自身へのリンクは意味がなく、スクリーンリーダーが「現在のページ」と読み上げることで位置を伝えます。

::before でセパレーターを表示
HTMLにセパレーター文字を書くのではなく、CSSの ::before 疑似要素で追加します。これにより、セパレーターの種類を変えたい時にCSSだけで対応でき、HTMLをクリーンに保てます。

コード解説

<!-- nav要素 → ナビゲーション領域を示す -->
<!-- aria-label → 他のnavと区別するためのラベル -->
<nav class="bc" aria-label="パンくずリスト">

  <!-- ol → 順序付きリスト。階層構造の順番を意味的に表現 -->
  <ol class="bc__list">
    <!-- 各階層をliで記述 -->
    <li class="bc__item">
      <a href="/" class="bc__link">ホーム</a>
    </li>
    <li class="bc__item">
      <a href="/products" class="bc__link">製品</a>
    </li>
    <li class="bc__item">
      <a href="/products/category" class="bc__link">カテゴリ</a>
    </li>

    <!-- 最後の項目：現在のページ -->
    <!-- span（リンクでない） + aria-current="page" -->
    <li class="bc__item">
      <span class="bc__current" aria-current="page">商品名</span>
    </li>
  </ol>
</nav>
/* ol のリストマーカーを消し、横並びに */
.bc__list {
  display: flex;
  flex-wrap: wrap; /* 幅が狭い時に折り返す */
  list-style: none; /* 1. 2. 3. のマーカーを消す */
  padding: 0;
  margin: 0;
}

/* --- セパレーターを ::before で自動挿入 --- */
/* + は「隣接兄弟セレクタ」。最初の項目以外にセパレーターを付ける */
.bc__item + .bc__item::before {
  content: '/';        /* ここを '›' に変えれば矢印になる */
  margin: 0 8px;
  color: var(--color-neutral-300);
  user-select: none;   /* テキスト選択時にセパレーターを除外 */
}

/* 現在のページ：太字で目立たせ、リンクにしない */
.bc__current {
  color: var(--color-neutral-800);
  font-weight: var(--font-medium);
}

/* ホバー時のスタイル：リンクであることを示す */
.bc__link:hover {
  color: var(--color-brand-600);
  text-decoration: underline;
}
