設計の意図

details/summary を使う理由
HTML標準の折りたたみ要素を使えば、JavaScriptなしで開閉が動作します。アクセシビリティも最初から組み込まれており、スクリーンリーダーが「展開済み」「折りたたみ済み」を自動で読み上げます。

aria-current="page" でアクティブ表示
現在のページを示すには aria-current="page" を使います。視覚的には左ボーダーと色の変化で、スクリーンリーダーには「現在のページ」として伝わります。

左ボーダーのインジケーター
アクティブなリンクの左に色付きボーダーを表示することで、どこにいるかが一目でわかります。色だけでなく太さと位置で判別できるため、色覚多様性にも配慮しています。

コード解説

<!-- nav要素でサイドバー全体を囲む -->
<nav class="sidebar" aria-label="サイドメニュー">

  <!-- details → 折りたたみ可能なセクション。open属性で初期展開 -->
  <details class="sidebar__section" open>

    <!-- summary → クリックで開閉するヘッダー部分 -->
    <summary class="sidebar__heading">はじめに</summary>

    <ul class="sidebar__list">
      <!-- aria-current="page" → 現在表示中のページ。
           スクリーンリーダーが「現在のページ」と読み上げる -->
      <li><a href="/overview" class="sidebar__link"
             aria-current="page">概要</a></li>
      <li><a href="/install" class="sidebar__link">インストール</a></li>
    </ul>
  </details>

  <!-- open属性なし → 初期状態で折りたたまれている -->
  <details class="sidebar__section">
    <summary class="sidebar__heading">上級者向け</summary>
    <ul class="sidebar__list">
      <li><a href="/theme" class="sidebar__link">テーマカスタマイズ</a></li>
    </ul>
  </details>
</nav>
/* --- details/summaryのデフォルトスタイルを消す --- */
.sidebar__heading {
  list-style: none; /* ▶マーカーを消す */
  cursor: pointer;
  user-select: none;
}
/* Safariでは::-webkit-details-markerで消す */
.sidebar__heading::-webkit-details-marker { display: none; }

/* カスタム矢印アイコン → ::afterで追加 */
.sidebar__heading::after {
  content: '';
  width: 16px;
  height: 16px;
  /* SVGをインラインで埋め込み → 画像ファイル不要 */
  background-image: url("data:image/svg+xml,...");
  transition: transform var(--duration-fast);
}

/* 開いた時に矢印を90度回転 */
.sidebar__section[open] > .sidebar__heading::after {
  transform: rotate(90deg);
}

/* --- アクティブリンクの左ボーダーインジケーター --- */
.sidebar__link[aria-current="page"] {
  color: var(--color-brand-600);
  font-weight: var(--font-semibold);
  background: var(--color-brand-50);
  /* 左に3pxのブランドカラーボーダーで「ここにいる」を示す */
  border-left: 3px solid var(--color-brand-500);
}

/* --- 開閉アニメーション --- */
@keyframes sidebar-expand {
  from { max-height: 0; opacity: 0; }
  to   { max-height: 500px; opacity: 1; }
}

.sidebar__section[open] .sidebar__list {
  animation: sidebar-expand 250ms ease-out;
}
