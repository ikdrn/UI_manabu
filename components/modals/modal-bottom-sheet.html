ボトムシート

画面下部から滑り上がるモバイル向けのUIパターン。アクション一覧やオプション選択に使い、ドラッグで閉じることができます。片手操作に最適化された、モバイルファーストなコンポーネントです。

設計の意図

なぜ下からスライドするのか？
スマートフォンを片手で持つとき、親指の届きやすい範囲は画面下部です。ボトムシートは操作対象を画面下部に配置することで、片手での操作性を最大化します。iOSのShare SheetやAndroidのBottom Sheetなど、主要なモバイルOSでも標準パターンとして採用されています。

ドラッグハンドルの役割
上部の小さなバー（ドラッグハンドル）は、「この要素はドラッグで操作できる」ことを視覚的に伝えるアフォーダンスです。ユーザーがハンドルを下方向にドラッグすると、シートが閉じるジェスチャーが発動します。

position: fixedの使い方
bottom: 0; left: 0; right: 0;でビューポートの下端に固定し、transform: translateY(100%)で画面外に隠します。開くときにtranslateY(0)にすることで、下からスライドするアニメーションになります。

危険な操作の視覚的分離
「削除する」のような不可逆な操作は、区切り線で他のアクションと視覚的に分離し、赤色で警告を示します。誤タップを防ぐための重要なデザインパターンです。

     画面全体を覆う */

  opacity: 0;
  visibility: hidden;
  transition: opacity 300ms ease, visibility 300ms ease;
}

.bottom-sheet-backdrop.is-active {
  opacity: 1;
  visibility: visible;
}

/* シート本体 */
.bottom-sheet {
  /* position: fixed → ビューポートに対して固定配置 */
  position: fixed;
  /* bottom: 0 → 画面の下端に配置 */
  bottom: 0;
  left: 0;
  right: 0;
  z-index: 1000;
  background: #fff;
  /* 上側だけ角丸 → 下から出てくる「シート」の形状 */
  border-radius: 16px 16px 0 0;
  box-shadow: 0 -4px 24px rgba(0, 0, 0, 0.15);

  /* 初期状態：画面外（下）に隠す */
  transform: translateY(100%);
  transition: transform 300ms ease;

  max-height: 80dvh;
  display: flex;
  flex-direction: column;

  /* touch-action: none → ブラウザのデフォルトのタッチ操作
     （スクロール等）を無効化し、独自のドラッグ処理を行う */
  touch-action: none;
}

.bottom-sheet.is-active {
  /* 表示状態：元の位置にスライドアップ */
  transform: translateY(0);
}

const sheet = document.getElementById('bottomSheet');
const backdrop = document.getElementById('backdrop');
const handle = document.getElementById('handle');

// シートを開く
function openBottomSheet() {
  sheet.classList.add('is-active');
  backdrop.classList.add('is-active');
  // 背景スクロールを防止
  document.body.classList.add('no-scroll');
}

// シートを閉じる
function closeBottomSheet() {
  sheet.classList.remove('is-active');
  backdrop.classList.remove('is-active');
  document.body.classList.remove('no-scroll');
}

// 背景クリックで閉じる
backdrop.addEventListener('click', closeBottomSheet);

// ===== ドラッグで閉じる処理 =====
let startY = 0;       // ドラッグ開始時のY座標
let currentY = 0;     // 現在のY座標
let isDragging = false;

// touchstart → ドラッグ開始
handle.addEventListener('touchstart', (e) => {
  isDragging = true;
  startY = e.touches[0].clientY;
  // transitionを無効にして、指の動きに直接追従させる
  sheet.style.transition = 'none';
});

// touchmove → ドラッグ中
handle.addEventListener('touchmove', (e) => {
  if (!isDragging) return;
  currentY = e.touches[0].clientY;
  // deltaY → 下方向に動いた距離（正の値）
  const deltaY = Math.max(0, currentY - startY);
  // シートを下にずらす
  sheet.style.transform = `translateY(${deltaY}px)`;
});

// touchend → ドラッグ終了
handle.addEventListener('touchend', () => {
  isDragging = false;
  // transitionを戻してアニメーションさせる
  sheet.style.transition = 'transform 300ms ease';

  const deltaY = currentY - startY;
  // 100px以上下にドラッグしたら閉じる
  if (deltaY > 100) {
    closeBottomSheet();
  } else {
    // 閾値未満なら元に戻す
    sheet.style.transform = 'translateY(0)';
  }
});

実運用でのエッジケース

多数のアクション項目

アクション数が多い場合、max-heightで制限しoverflow-y: autoでスクロール可能にしています。ドラッグとスクロールの競合を防ぐため、ドラッグはハンドル部分のみで受け付けます。

マウス環境でのドラッグ

タッチイベント（touchstart/touchmove/touchend）はモバイル向けです。デスクトップ環境ではmousedown/mousemove/mouseupイベントも併用するか、背景クリックやキャンセルボタンで閉じる方法を提供します。

アクセシビリティ

dialog要素ではないため、role="dialog"とaria-modal="true"を手動で設定しています。また、フォーカストラップやEscapeキーでの閉じる処理もJavaScriptで実装する必要があります。
