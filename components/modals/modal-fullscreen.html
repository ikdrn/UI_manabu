モーダル

フルスクリーンモーダル

画面全体を覆うモーダル。長文の利用規約やプレビュー画面など、ユーザーの注意を完全に集中させたい場面で使います。下からスライドアップするアニメーションで画面遷移のような体験を提供します。

設計の意図

なぜdvh単位を使うのか？
dvh（Dynamic Viewport Height）はモバイルブラウザのアドレスバーの表示・非表示を考慮した高さ単位です。vhだと、モバイルでアドレスバーが表示されている時に画面の下部が隠れてしまいますが、dvhなら常に正しい表示領域の高さを取得できます。

下からのスライドアップアニメーション
translateY(100%)から0への遷移は、「新しい画面が下から現れる」というモバイルアプリでお馴染みのパターンです。通常のモーダルのフェード＋スケールとは異なり、「別の画面に移動した」感覚を与えます。

背景スクロールの防止
<dialog>のshowModal()はブラウザが自動的に背景のスクロールを防止します。divで作ったモーダルの場合はbody { overflow: hidden }を手動で制御する必要がありますが、dialog要素ならその心配がありません。

コンテンツの最大幅制限
フルスクリーンでも本文の幅は640px程度に制限しています。1行が長すぎると読みにくくなるため（最適な行長は50〜75文字）、大画面でもコンテンツに集中しやすい幅に抑えます。

コード解説

<!-- dialog → フルスクリーンで使う場合もdialog要素が最適 -->
<dialog id="fullscreenDialog" class="fullscreen-dialog">
  <!-- layout → flexで縦に3分割（ヘッダー・コンテンツ・フッター） -->
  <div class="fullscreen-dialog__layout">

    <!-- ヘッダー — flex-shrink: 0で固定高さ -->
    <header class="fullscreen-dialog__header">
      <h3 class="fullscreen-dialog__title">利用規約</h3>
      <!-- 閉じるボタン → aria-labelでスクリーンリーダーに意味を伝える -->
      <button type="button" class="fullscreen-dialog__close"
              aria-label="閉じる">✕</button>
    </header>

    <!-- コンテンツ — flex: 1 + overflow-y: autoでスクロール -->
    <div class="fullscreen-dialog__content">
      <div class="fullscreen-dialog__inner">
        <h2>サービス利用規約</h2>
        <p>本利用規約は...</p>
        <!-- 長いコンテンツ -->
      </div>
    </div>

    <!-- フッター — flex-shrink: 0で固定高さ -->
    <footer class="fullscreen-dialog__footer">
      <button type="button" class="fullscreen-dialog__btn">
        閉じる
      </button>
      <button type="button"
              class="fullscreen-dialog__btn fullscreen-dialog__btn--primary">
        同意する
      </button>
    </footer>

  </div>
</dialog>
/* フルスクリーンダイアログ */
.fullscreen-dialog {
  border: none;
  padding: 0;
  margin: 0;
  width: 100%;
  /* dvh → Dynamic Viewport Height。
     モバイルのアドレスバーの高さ変化に対応する単位。
     vhだとアドレスバー分の誤差が出る */
  height: 100dvh;
  /* max-width/max-height → dialogのデフォルト制限を解除 */
  max-width: 100%;
  max-height: 100dvh;
  background: #fff;

  /* 下からスライドアップ */
  animation: slide-up 300ms ease-out;
}

@keyframes slide-up {
  from {
    /* translateY(100%) → 画面の高さ分だけ下にずらす（画面外） */
    transform: translateY(100%);
  }
  to {
    /* translateY(0) → 元の位置に戻す（画面内） */
    transform: translateY(0);
  }
}

/* レイアウト — 縦方向のflexbox */
.fullscreen-dialog__layout {
  display: flex;
  flex-direction: column;
  height: 100dvh;
}

/* コンテンツ領域 — 残りの高さ全てを使う */
.fullscreen-dialog__content {
  /* flex: 1 → ヘッダーとフッターの余りのスペースを全て使う */
  flex: 1;
  /* overflow-y: auto → 内容が溢れたらスクロール */
  overflow-y: auto;
  padding: 24px 20px;
  /* -webkit-overflow-scrolling: touch → iOSでなめらかなスクロール */
  -webkit-overflow-scrolling: touch;
}

/* コンテンツの最大幅 */
.fullscreen-dialog__inner {
  /* max-width: 640px → 読みやすい行長に制限 */
  max-width: 640px;
  margin: 0 auto;
}
const dialog = document.getElementById('fullscreenDialog');

// モーダルを開く
function openFullscreenDialog() {
  // showModal() → モーダルとして開く
  // 自動的に背景スクロールが防止される
  dialog.showModal();

  // bodyのoverflowをhiddenにする必要がない
  // dialog要素のshowModal()が自動で処理する
}

// モーダルを閉じる
function closeFullscreenDialog() {
  dialog.close();
}

// Escapeキーでの閉じるはshowModal()が自動処理
// ただし、閉じる前に確認を挟みたい場合は：
dialog.addEventListener('cancel', (e) => {
  // e.preventDefault()で閉じるのを防止できる
  // 例：フォームに未保存の変更がある場合
});

実運用でのエッジケース

モバイルでのdvhサポート

dvh単位は主要な最新ブラウザでサポートされていますが、古いブラウザにはフォールバックとしてvhを併記します。height: 100vh; height: 100dvh; のように書くと、dvh未対応ブラウザはvhを使います。

閉じるアニメーション

dialog要素のclose()は即座に非表示にするため、閉じるアニメーションを付けるにはCSSの@starting-styleルールやJavaScriptでアニメーション完了後にclose()を呼ぶ処理が必要です。

キーボードのスクロール

フルスクリーンモーダル内のスクロール領域にtabindex="0"を付けると、キーボードの矢印キーでもスクロールできるようになります。長い利用規約などではアクセシビリティの向上に役立ちます。
