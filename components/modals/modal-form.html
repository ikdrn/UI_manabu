フォームモーダル

タスクの新規作成など、短いフォーム入力をモーダル内で完結させるパターン。<form method="dialog">を使うことで、送信時にダイアログが自動的に閉じます。

プレビュー

タスクを作成

任意。タスクの背景や目的を記入してください。

設計の意図

なぜ<form method="dialog">を使うのか？
method="dialog"を指定すると、フォームの送信ボタンを押したときにページ遷移やリロードが起きず、代わりにダイアログが自動的に閉じます。JavaScriptでpreventDefault()を書く必要がなく、ブラウザのネイティブなバリデーションもそのまま使えます。

バリデーションの仕組み
required属性を使ったHTML標準のバリデーションにより、空のタスク名では送信できません。:invalid:not(:placeholder-shown)セレクタで、ユーザーが入力を始めた後にだけエラー状態を表示し、初回表示時に赤枠が出る問題を防ぎます。

フォームモーダルの適切な使いどころ
入力項目が3〜5つ程度の短いフォームはモーダルに適しています。それ以上の項目数になる場合は、専用のページに遷移した方がユーザーの集中力を維持しやすくなります。

閉じるボタン（✕）の配置
ヘッダー右上の✕ボタンは、ユーザーが「いつでも離脱できる」安心感を与えます。キャンセルボタンとの重複に見えますが、✕は視線の流れ（右上）で自然に見つかる位置にあるため、両方あることでユーザビリティが向上します。

コード解説

<dialog id="formDialog" class="form-dialog">
  <!-- ヘッダー → タイトルと閉じるボタン -->
  <div class="form-dialog__header">
    <h3 class="form-dialog__title">タスクを作成</h3>
    <button type="button" class="form-dialog__close"
            aria-label="閉じる">✕</button>
  </div>

  <!-- form method="dialog" → 送信でダイアログが自動的に閉じる -->
  <form method="dialog">
    <div class="form-dialog__body">

      <!-- タスク名（必須入力） -->
      <div class="form-group">
        <label class="form-group__label form-group__label--required"
               for="taskName">タスク名</label>
        <input type="text" id="taskName"
               class="form-group__input"
               placeholder="例：デザインレビューを実施"
               required>
      </div>

      <!-- 説明（任意） -->
      <div class="form-group">
        <label class="form-group__label"
               for="taskDesc">説明</label>
        <textarea id="taskDesc"
                  class="form-group__textarea"
                  placeholder="タスクの詳細を入力..."></textarea>
        <span class="form-group__hint">任意</span>
      </div>

      <!-- 優先度（セレクトボックス） -->
      <div class="form-group">
        <label class="form-group__label"
               for="taskPriority">優先度</label>
        <select id="taskPriority"
                class="form-group__select">
          <option value="low">低</option>
          <option value="medium" selected>中</option>
          <option value="high">高</option>
          <option value="urgent">緊急</option>
        </select>
      </div>

    </div>

    <div class="form-dialog__footer">
      <button type="button" class="form-dialog__btn">
        キャンセル
      </button>
      <!-- type="submit" → フォームバリデーション後に送信 -->
      <button type="submit"
              class="form-dialog__btn form-dialog__btn--primary">
        作成する
      </button>
    </div>
  </form>
</dialog>
/* ダイアログ本体 */
.form-dialog {
  border: none;
  border-radius: 12px;
  padding: 0;
  max-width: 480px;
  width: 90%;
  background: #fff;
  box-shadow: 0 20px 60px rgba(0, 0, 0, 0.3);
  animation: form-dialog-enter 250ms ease-out;
}

/* ::backdrop → モーダル背景 */
.form-dialog::backdrop {
  background: rgba(0, 0, 0, 0.5);
}

/* フォーム入力フィールドのフォーカス状態 */
.form-group__input:focus,
.form-group__textarea:focus,
.form-group__select:focus {
  outline: none;
  /* ブランドカラーの枠線でフォーカスを示す */
  border-color: var(--color-brand-500);
  /* box-shadow → 枠線の外側にうっすら色を広げる（グロー効果） */
  box-shadow: 0 0 0 3px hsla(222, 80%, 50%, 0.15);
}

/* バリデーションエラー状態 */
.form-group__input:invalid:not(:placeholder-shown) {
  /* :invalid → HTML標準のバリデーションに失敗した状態 */
  /* :not(:placeholder-shown) → プレースホルダーが見えていない
     ＝ユーザーが入力を始めた後にだけ赤枠を表示 */
  border-color: #ef4444;
}

/* カスタムセレクトボックス */
.form-group__select {
  /* appearance: none → ブラウザデフォルトの矢印を消す */
  appearance: none;
  /* SVGの矢印アイコンを背景画像として配置 */
  background-image: url("data:image/svg+xml,...");
  background-repeat: no-repeat;
  background-position: right 12px center;
  /* 矢印アイコン分の余白を確保 */
  padding-right: 36px;
}
const dialog = document.getElementById('formDialog');
const form = document.getElementById('taskForm');

// ダイアログを開く
dialog.showModal();

// 閉じるボタン（✕）の処理
const closeBtn = dialog.querySelector('.form-dialog__close');
closeBtn.addEventListener('click', () => {
  dialog.close();
});

// キャンセルボタンの処理
const cancelBtn = dialog.querySelector('.form-dialog__btn:not(.form-dialog__btn--primary)');
cancelBtn.addEventListener('click', () => {
  dialog.close();
});

// 背景クリックで閉じる
dialog.addEventListener('click', (e) => {
  if (e.target === dialog) {
    dialog.close();
  }
});

// フォーム送信時の処理
// method="dialog"のため、submit後にダイアログが自動で閉じる
form.addEventListener('submit', (e) => {
  // フォームデータを取得
  const formData = new FormData(form);
  console.log('タスク名:', formData.get('taskName'));
  console.log('優先度:', formData.get('taskPriority'));

  // 送信後にフォームをリセット
  form.reset();
});

実運用でのエッジケース

バリデーションエラー時

required属性付きの入力欄が空のまま送信ボタンを押すと、ブラウザ標準のバリデーションメッセージが表示されます。method="dialog"でもバリデーションは正しく動作します。

フォームのリセット

ダイアログを閉じた後にform.reset()を呼ばないと、再度開いた時に前回の入力値が残ります。closeイベントでリセットするのがベストプラクティスです。

モバイルでのキーボード表示

モバイルデバイスでは、テキスト入力にフォーカスするとソフトウェアキーボードが表示されます。ダイアログのmax-heightをビューポート高さに制限し、スクロール可能にすることで、キーボード表示時にもフォームが操作できるようにします。
